# 打包与语音服务（sidecar）

## 结论先说：模型不塞进安装包

| 部件 | 体积 |
|---|---|
| Irodori-TTS（含 `.venv`） | 12 GB |
| 耳用的 python runtime（GSV runtime） | 7.4 GB |
| 耳模型（paraformer + funasr） | 4.0 GB |
| **合计** | **≈ 23 GB** |

23 GB 无法做成常规安装包（NSIS 单文件上限 2 GB），所以采用 **A 方案**：
**安装包保持正常体积，exe 启动时自动把语音服务拉起来；模型放在约定目录，路径可配。**

## 运行时的行为

壳（主进程）启动时会调用 sidecar 启动器，依次处理三个服务：

| 服务 | 端口 | 启动方式 |
|---|---|---|
| Irodori 后端 | 9889 | `<irodori>/\.venv/Scripts/python.exe -u irodori_serve.py` |
| TTS 桥 | 9881 | 同上，`-u bridge.py` |
| 耳（STT） | 9882 | `<pythonExe> whisper_serve.py`（cwd = 耳目录，注入 `ALBION_STT_ENGINE=paraformer`） |

规则：

- **端口已在听就跳过** —— 所以和你手动双击的 bat 是幂等的，不会起两份
- 退出时只杀「本次自己拉起来的」那些进程，你在别的窗口跑的实例一律不碰
- 日志形如：`[albion-sidecars] 启动 耳朵（:9882）pid=29108` / `… 已在跑（:9889），跳过`
- 想彻底关掉这套自启：设环境变量 `ALBION_SIDECARS=0`

## 模型目录怎么找（四级回退）

按顺序取第一个命中的：

1. 环境变量：`ALBION_IRODORI_DIR`、`ALBION_EAR_DIR`、`ALBION_GSV_PYTHON`
2. **设置文件**：`%APPDATA%\ai.moeru.airi\albion-sidecars.json`
   ```json
   {
     "irodoriDir": "D:/AI/Wife/tts/irodori",
     "earDir": "D:/AI/Wife/pet",
     "pythonExe": "D:/AI/Wife/tts/GPT-sovits/runtime/python.exe"
   }
   ```
   托盘右键 → **语音服务 → 打开 sidecar 配置（模型目录）** 会生成/打开这个文件
3. 打包约定：`<安装目录>\resources\sidecars\irodori`、`…\sidecars\ear`（绿色包把模型放这儿就自动认）
4. 开发机默认路径（`D:/AI/...`）

## 托盘里的状态显示

右键托盘图标 → **语音服务**：

```

TTS 桥 :9881        就绪 / 未就绪
耳·STT :9882        就绪 / 未就绪
────────────
重新拉起语音服务        ← 手动重试启动
打开 sidecar 配置（模型目录）
```

状态每 5 秒探一次端口，只有变化时才重建菜单（托盘菜单是静态的，只能重建）。

## 内置服务商（不用手动配）

应用内的默认服务来源就是这三个本地服务：

| 用途 | provider | 默认地址 |
|---|---|---|
| 脑（LLM） | `openai-compatible`（模型名 `albion`） | `http://127.0.0.1:8650/v1` |
| 嘴（TTS） | `openai-compatible-audio-speech`（model/voice = `albion`） | `http://127.0.0.1:9881/v1` |
| 耳（STT） | `openai-compatible-audio-transcription`（`paraformer-zh`） | `http://127.0.0.1:9882/v1` |

兜底值写在 `shell/packages/stage-ui/src/albion/albion-defaults.ts`，`.env.local` 里的 `VITE_ALBION_*` 可以覆盖。
**唯一必须手填的是 LLM 的 key**（Pi 宿主的 `API_SERVER_KEY`，值在 WSL `/root/albion-pi/agent/.env`，属机密，不能写进代码）：
填在应用设置的「服务来源」里，或开发时写进 `.env.local` 的 `VITE_ALBION_LLM_KEY`。

## 如果要换机器（绿色目录的做法）

1. 拷 `D:\AI\Wife\tts\irodori\`（含 `.venv`）到目标机
2. 拷耳目录：`whisper_serve.py` + `models\`（paraformer）
3. 拷 python runtime（GSV runtime，7.4 G）
4. 把 exe + 上述目录按 `sidecars/{irodori,ear}` 摆好（或用设置文件指路径）
5. 起 exe → 托盘「语音服务」三项都显示"就绪"即可

> 注：`.venv` 里的路径是绝对路径，换盘符/换用户名时可能需要重建虚拟环境。
