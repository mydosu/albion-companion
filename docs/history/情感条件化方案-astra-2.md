# 情感条件化补充方案：从规则优先改为证据融合，从七锚改为可验证的发声覆盖

日期：2026-09-28。范围：设计、只读核查与统计；本轮只写本文，不改生产代码、配置、模型或数据，不重启，不调用合成或训练。续接《情感条件化方案-astra.md》，不重复建设已经落地的 v3 内核。

## 结论

建议把下一步分成两条可独立验收的工作线：**CPU 侧先提高判断质量；声学侧用单船小实验确认新的日语描述词确实可学、可听辨，再扩到五船。** NSFW 场景的技术优先级落实为弱声、气声、耳语、断续和气息变化的覆盖与误触发指标，不靠增加露骨词汇。

1. 保留现有七句训练锚、固定族 CFG、平滑推进和成功后提交机制。增加一个有置信度的融合器，汇总 LLM、日语词义、中文源信号、韵律和前文的证据；有限词典只提取特征，不再由首条命中裁决。
2. 把目标情绪/发声方式与最终可用 caption 分开记录。五个 family 本身不是完整情绪分类体系；“高唤醒负效价”不能因为没有愤怒锚就被统计成“识别正确的 bright”。识别、码本覆盖、合成表现分别验收。
3. 用 **200 条本地自标文本**启动校准；按会话及改写来源分组，80/40/80 划分拟合、验证、封存测试。先做无 GPU 的识别评测，再安排后续声学盲测。当前准确率未知，不从 caption 数量或时长变化推导准确率。
4. 七句是现有已登记 caption 的上限，不是底模所有潜在表达能力的上限。当前有 **7 个不同 caption、9 个合法 family/caption/cfg 三元组**，但没有证据证明存在 7 个、更没有证据证明存在 9 个独立可听辨情绪。CFG 与时长可以改变声音，不能直接记作新增情绪锚。
5. 最小扩锚实验：先选阿尔比恩，4 个发声候选 × 24 条真实录音＝96 条新目标样本，加 64 条旧风格回放，合计 **160 条**。这是用于证伪路线的建议起点，不是保证成功的最少数据定律。先探索 400–600 步的单船 LoRA；本机工时只给条件预算，不能假装已测。

## 第一问：更智能——五路证据融合，低置信度不切换

### 1.1 内部状态不等于送给模型的条件

内部诊断允许数值及标签；送入合成器的风格可控条件始终是白名单中的**完整日语短句**，不新增连续情绪 token，不将中文括号或英文分类标签作为 caption。

建议新建 `emotion_fusion.py`，返回三个层次：

- `target`：arousal、valence、intensity 的估计与缺失掩码；phonation 分布；delivery 的 weak/broken/uneven/near 证据；允许 unknown，不强填 0。
- `decision`：五族分数/归一化分布、置信度、是否继承、可接受候选集合、`coverage_gap`。flirty 的依据是互动语用；intimate 的依据是近距离交流意图，不能仅用气声猜它们。
- `compiled`：现有合法 family/caption/cfg；新条件目录成熟后再接版本化码本。记录为何降级为近似表达，但不把降级 caption 当成人工真值。

“生气但压低声音”可以是负效价、较高心理唤醒、soft；“安静说明”可以是 neutral+soft。现有五族无法完全表达这两个目标。第一阶段允许输出保守的既有锚并标记覆盖不足；不能因输出约束而篡改 target。现有 flirty/intimate 共用两个 caption，仅 cfg 不同；需要同时报告五族语用准确率和合并两族后的声学路由准确率。

### 1.2 源信号必须带范围，先保留再清理

以 `SessionText.text/kinds` 的原始范围为来源，由协调器提取 `source_cues`；不改变 speech/aside/control 的原有朗读规则。字段建议为 `{kind, value, span, scope, origin_id, reliability}`，再附自然句 `parent_id` 与 `complete`。所有新增字段仅在新策略开关下发送。

| 源 | 提取方法与支持的证据 | 边界 |
|---|---|---|
| LLM 提示 | 有效有限数值映射到 A/V/I，四种 phonation 为分布初值 | 排除 bool、NaN、Inf、越界；缺字段保持缺失；LLM 自称 confidence 不作为校准概率 |
| 日语文本 | 有限词典对多个类别同时计分；否定、引用、不确定性作为范围特征 | “泣かないで”不是说话者正在哭；不以一个词强行翻转全部轴 |
| 中文原始提示 | 结构化抽取括号短指令、emoji 类别、拟声与作用域 | `（小声）`支持 soft；`（别小声）`不支持 soft；`（她小声说）`为转述证据；心声不送去朗读 |
| 韵律 | 句长、标点连串长度、重复字符比例、省略/停顿密度，均截断或归一化 | `!!!`主要支持高唤醒，不支持正效价；长句不是低情绪真值；拟声必须查左右词界 |
| 前文 | 已成功渲染的短上下文、上一族分布和递进方向；新场景重置 | 前文是弱先验；不把未来句或未渲染成功内容加入判定 |

`source_cues` 必须绑定到源子句：emoji 不能复制到随后全部译文；源句译成多个子段时共享来源 ID，只计算一次独立证据。对齐不确定时只保留 unit 范围弱先验并降低可靠度，不能凭下标强认字级对齐。独立的括号 no_audio 单元可以产生“待作用提示”，仅作用下一完整自然句，消费后失效；不把 no_audio 本身记作已发声状态，也不跨 generation 继承。

日语直通也走相同提取器；没有 LLM 提示是合法缺失。更长远可以把有界前文和结构提示送进现有同次翻译调用，但它是可选改进；先用 CPU 汇聚即可，不增加在线第二次分类请求。现有翻译失败退路可能重译，不能把“复用调用”解释为绝对只有一次网络调用。

### 1.3 可计算、可解释的分数形式

先将每路证据变成每族支持值 `u[k,f] ∈ [-1,1]`，0 表示无信息；负值代表反证。不要先将每路压成一个赢家。词典只生成带强度、否定和来源的特征向量；最终用加权求和比较所有族。

LLM 的 A/V/I 使用少量固定三角隶属函数，例如 highA=A、lowA=1-A、posV=max(V,0)、negV=max(-V,0)，phonation 分量独立保留。交互项 highA×posV 支持 bright；highA×negV 产生“高唤醒负效价”目标和覆盖缺口；lowA×negV 支持 sad。phonation 单独不产生 flirty 证据。每族特征系数放数据表，用标注集只调少量全局权重，不拟合大模型。

```text
E[f] = sum_k w[k] * r[k] * u[k,f]                 # 当句四路证据
H[f] = 2 * p_previous[f] - 1                     # 前文先验，不计作新信号
S[f] = b[f] + E[f] + w_history * decay * H[f]
p[f] = softmax(S[f] / T)
decision = selective_switch(p, current_evidence, conflict, previous)
caption = compile_supported_japanese_anchor(target, decision, codebook)
state = commit_once_only_after_success(decision)
```

这里 T 负责温度校准；softmax 在校准前只是归一化分数，不能称为真实正确概率。对 LLM、译文关键词和源标点这些相关特征使用同一个 origin_id 和来源预算，避免同一个感叹号在三路被算成三份独立支持。缺失路不重新均分权重，否则只有一个 emoji 的句子也会显得“满证据”。

冷启动权重**仅是待校准的设计初值**：LLM 0.40、日语词义 0.15、中文源信号 0.25、韵律 0.10、前文 0.10；b 初始全 0。可靠度 r：合法 LLM 暂设 0.7、明确直述发声指令 1.0、模糊 emoji/拟声 0.3–0.5、可靠日语语义 0.7。LLM 与原文发声指令明确冲突时，将 LLM 的对应 phonation 分量可靠度降至 0.3，并输出 conflict；不降低与冲突无关的效价信息。权重大小不代表已证明哪路最准。

句长、重复等只对 A/I 和停连目标有直接贡献，映射 family 必须结合效价/语用证据。flirty/intimate 在 A/V/P 上本来就可相同；没有额外互动证据时二者只能得到相近分数，正确动作是保留歧义而不是发明识别能力。

强度另行融合：对有效 I/韵律强度采用可靠度加权均值；没有当前强度证据则沿用现有衰减。仍用 `step_level(max_step=0.34)`，但耳语、soft 不再简单等价为强气息锚的低档；当目标 phonation 不允许粗气息时，对不匹配候选加入代价或禁用。初期从现有 allowed_pairs 中挑最接近的锚，记录 `coverage_gap`，不要现场改写日语措辞。

### 1.4 何时不切，以及如何避免永远继承

建议验证集调参的起始门槛：最高概率 ≥0.60、与第二名差 ≥0.20、当前证据质量 Q≥0.35 才考虑切换。Q 由当前有效可靠度加权求和，明确排除前文；全缺失时 Q=0。门槛不满足则保留上一族并推进“无足够新证据”计数；开始无前文则 neutral 弱锚。这些阈值在校准前没有概率承诺。

为防小标注集把“（小声）”这种明确指令过滤掉，发声目标与 family 分开门控：明确作用于本人当前话语的发声指令，可在同族内选择更匹配的已有锚；若不存在匹配锚，就记录缺口，不强切到 intimate。用户显式 style_override 仍作为既有最高优先级控制，不参加统计意义上的情绪推断。

新 fusion 策略建议定义“连续 8 个完整自然句无新证据，在第 8 句编译前释放”；旧 v3 的第 9 单元释放语义保持原样。只有硬句界/finish 才累加一次，soft/force 子段不重复衰减。不能等待未来文本阻塞首音：不完整句先用已有证据规划，收到新片段后只影响后续片段，不改已播声音。state 带 generation、parent_id、last_committed_sub_id，失败和重试不重复计数。场景切换、新 turn 或换船清空相关状态。

参考待标边界例（不是已标金标）：

| 文本/线索 | 融合应保留的判断 | 不能做的推断 |
|---|---|---|
| `（小声）这边，请慢一点。` | soft、低音量意图；语用可 neutral | 小声必定亲密，或必定无浊音耳语 |
| `我真的生气了！！！` | 负效价、高唤醒；愤怒锚缺口 | 高唤醒直接判开心 |
| `没事。`，前句低落 | 当前不确定，短暂继承；随完整句释放 | 把没有词表命中当成明确中性 |
| `别用气声，正常说。` | voiced 正证据，breathy 反证据 | 命中“气声”就切强锚 |
| `她说“轻一点”，我没听清。` | 引用/叙述，弱化本人发声指令 | 将引号内容施加给整句 |
| `太好了……` | posV 有证据，唤醒度可能低 | 省略号一定悲伤或断续呼吸 |

### 1.5 用很小的集合校准

先标完第二问的 200 条，再固定分组。拟合 80 条只搜索四路全局权重，历史权重限制在 0–0.15；权重保持非负且总和≤1，向上述初值做 L2 收缩。不要同时自由拟合五族×几十个特征。phonation 识别和不支持目标的规则定义先固定。

验证 40 条只选 T∈{0.25,0.5,1,2}、置信门槛∈{0.55,0.60,0.65}、margin∈{0.10,0.20,0.30}；避免再全网格搜索几十种 decay。优先减少错误切换和日常误触发，遇到并列选参数更接近旧行为的方案。80 条封存测试只运行一次；如失败需要改设计，应新增下一批封存文本，而不是反复调到这个集合过线。

校准损失可用 `-sum_f q_gold[f] log p[f] + λ||w-w0||²`；歧义样本用人工分配的可接受集合均匀分布 q，仅表示弱监督，不宣称人类心理概率。分组交叉验证用于检查稳定性，不能代替封存测试。记录固定翻译结果、hint 和模型/提示词版本，旧规则、仅 LLM、融合器都使用同一输入，避免翻译随机性遮盖归因。

## 第二问：更准确——自己可做的分层评测

### 2.1 200 条怎么取、怎么标

建立本地 UTF-8 JSONL/CSV，每条包含 `case_id/group_id/source_zh/ja/context_before/source_cues/llm_hint/gold_family_set/gold_A/gold_V/gold_I/gold_phonation/gold_delivery/should_switch/evidence_span/coverage_gap`。未知项留空。上下文只展示该句之前内容，禁止用后续剧情倒推。标注工具不需要在线服务；表格编辑器即可。

样本按两个交叉维度配额：语用五族各约 30 条清晰样本＝150 条，加 50 条有意歧义/反例；其中至少 **100 条**覆盖弱声、气声、耳语、断续、贴近、气息不匀以及它们的日常反例，另 100 条日常/效价/唤醒变化。交叉配额不是额外加样。建议取约 40 个短会话，总计 200 条，保留几组 ≥9 句的释放序列，并包含中文、日语直通、翻译缺 hint、否定、转述、emoji 和软切边界。

同一句的标点变体、同一会话、同一原始音频对应的文本放同一 group；按 group 分到80/40/80，必要时微调组长实现总数。分配后列出实际各族、各 phonation 的 n，不保证每个稀有格都有统计能力。不要随机打散相邻句造成上下文泄漏。

标注时先隐藏模型输出。family 可填一个或两个可接受类别；“已有五族都不对”填 unsupported 并描述 A/V/P；A/I 用0、0.25、0.5、0.75、1，V用-1、-0.5、0、0.5、1；phonation 可多选/unknown。强度含义是表达幅度，不是音量，soft 是发声努力/音量意图，whispered 是耳语音质，两者不能混标为同义。

用户自己先标一次，隔至少一天将 40 条随机打乱重标，计算自身一致率；如有一名熟悉项目的本地参与者，再独立标这40条。没有第二人就明确写“单人重复一致性”，不能称为跨标注者一致性。冲突保留理由与允许集合，不让生成 hint 的同一 LLM 当裁判。预计人工工作量 200×30–60秒＝1.7–3.3小时，加重标20–40分钟，均为排期估计。

### 2.2 指标与分母

| 指标 | 计算/报告方法 | 解决的问题 |
|---|---|---|
| 清晰句 family accuracy、macro-F1 | 只对单一金标且受支持的样本计算；给每族 n 与5×5混淆矩阵 | 不能用 neutral 大类淹没小类 |
| 五族与合并路由双口径 | 另将 flirty/intimate 合为一类报告，原五族矩阵仍保留 | 分开语用区分与声学路由能力 |
| 歧义集合命中率 | `pred ∈ gold_family_set`，单独报告 n；歧义不强行并入清晰集准确率 | 合理边界不当成机械错题 |
| A/V/I 误差、phonation macro-F1 | 对各自有效标注字段算 MAE；发声方式另报混淆矩阵 | family 对不代表气声/耳语也对 |
| coverage_gap 检出率 | 人工 unsupported 为正例；报 precision/recall 与最终近似路由 | 不奖励把愤怒硬塞 bright |
| 切换错误率 | 应保持时实际切换的次数/应保持边界数；反向再报漏切率 | 不能以一直 neutral 获得虚假稳定 |
| 切换延迟、释放边界 | 在金标需要切换的自然句起点后，多少完整句才切；精确检查第8/9边界 | 继承不能无限拖延 |
| 选择性风险/覆盖率 | confident 子集错误率与其占比同时报告；低置信继承仍计入最终端到端准确率 | 不能全 abstain 后宣称100%准确 |
| 校准 | Brier、3–5个等频箱可靠性表；标出每箱 n | 避免在80条上报告精细十箱假精度 |
| 日常误触发 | 非亲密日常样本进入强气息 caption 的比例；另报纯soft错为whisper/breathy | NSFW高权重也必须控制串味 |

不确定性按会话 group 做配对 bootstrap；accuracy 另给二项区间用于直观参考。即使80条都是独立样本，准确率约80%的标准误也约4.5个百分点，95%区间宽度约±9个百分点；有会话相关性会更宽。小集能发现大错和验证方向，不能证明1–2个百分点提升。所有百分比旁附分子/分母，类别不足10条的结果仅作观察。

建议启动门槛是工程目标而非已实现成绩：融合器在封存集清晰句 macro-F1 相比旧 v3 提升至少5个百分点；phonation 不退步；封存集内发声相关子集报告独立结果（全库配额100条，封存实际n单列，不拿拟合样本报测试成绩）；日常强气息误触发目标≤5%，同时看区间；每100个应保持边界错误切换≤5次。小样本未能证明优势时维持影子模式，不按某一条听起来更好的样本上线。

### 2.3 区分识别错误、码本不足与渲染不足

对固定文本做以下因果拆分。所有合成是**后续实验计划，本轮未执行**；不接外部标注服务。

1. **文本判定评测**：只运行 CPU 特征/融合纯函数，使用缓存的翻译/hint，与人工 target 比较。到这里不产生任何 WAV。
2. **码本投影检查**：人工 target 是否有匹配的受支持 caption？若没有，归类“覆盖不足”，即使挑中了最近的旧锚，也不能算渲染器失败。
3. **oracle 合成**：人工指定正确且已支持的 caption，固定文本、船、speaker embedding/reference、模型/adapter 哈希、种子和实际有效 CFG；与自动选择 caption 的结果配对。oracle 表现好而自动差，主要指向识别/投影；oracle 也不表现目标，才去排查训练、条件或合成。
4. **链路核对**：记录 plan caption、render 接收 caption、`_run_infer` 实际参数及资产，确认不存在 caption 被覆盖、错误船、joint CFG 覆盖或尾部裁剪截掉气息；这类属于执行故障，不混入识别错误。

首轮小声学集：12条不含情绪关键词的日语中性台词 × 4种发声目标 × 2个固定种子＝96个 oracle WAV；对同48个文本/目标项目再生成96个自动规划 WAV，配对部分总计192个；再加同12条×2种子的普通voiced控制24个，共216个。如果自动与 oracle 的完整条件相同，可复用 WAV，但统计仍按48个配对项目，不将相同音频重复当新样本。第一船通过后，五船完整复核为1080个音频槽（实际生成可去重）；不在本次执行。

用户盲听随机文件名，先选 soft/breathy/whispered/uneven/unclear，再评清晰度、自然度、身份相似度各1–5分。20%音频隐藏重复，检查自我一致性；同句不同条件做 ABX 配对辨别，并按台词分组统计。目标候选与正常 voiced 控制的混淆也必须测，否则四种错误但相互不同的声音会显得成功。

可听辨的新锚暂定通过条件：标签识别≥75%、主要混淆对的二选辨别≥75%且区间下界超过机会水平50%、清晰度/身份评分无明显退化；样本不足以满足区间要求时加台词，不加同一台词重复种子充数。最终“新增几种条件”按通过辨识与质量门禁的锚数计算，不能按配置项数量计算。

### 2.4 声学数字怎样辅助，不能替代什么

将固定台词的音素/音节区间和可闻换气区间人工粗对齐，用 CPU Praat 或同类本地工具计算：有声帧比例、有效有声区 F0 分位差、CPP/CPPS、HNR、语速（假名音拍/秒，注明近似）、停顿占比、停顿间隔变异系数、呼吸段时长比例。CPP刻画倒谱峰高出背景的程度，HNR刻画周期成分与噪声的比例；参数和音素会影响数值。[Praat CPP说明](https://www.fon.hum.uva.nl/praat/manual/PowerCepstrum__Get_peak_prominence___.html)、[Praat HNR说明](https://uvafon.hum.uva.nl/praat/manual/Harmonicity.html)。

带浊音气声与普通有声语音可比较同元音的周期性/噪声；耳语的 F0 经常不可可靠定义，应记 NA，不能拿0 Hz当作低沉或算 jitter。低 HNR 也可能是底噪、嘶声辅音或失真，不是“气声成功”的充分条件。响度降低能被后处理归一化抹掉，因此同时保留原响度版本和听辨音量匹配版本；近距离主要是感知与录音条件，不能只凭单个频谱数值认定。

用同一声音、同一文本、相同处理条件的配对变化做佐证；不要跨五船设统一 HNR/F0 阈值。ASR/CER可离线检查漏字，优先由用户核对这批短文本；自动ASR对耳语也可能失败，不能只凭ASR惩罚正确的耳语。声学特征只能证明声学差异，不能自动证明自然度、语用准确或接近真人。

## 第三问：更全面——现有能力边界与小 LoRA 最小实验

### 3.1 七个锚到底限制了什么

现有码本 2+2+1+2+2＝9 个合法三元组；flirty/intimate 共享两句 caption，所以只有7种文字条件。不同文本、说话人、采样和引导会产生远多于7种波形；这与具有多少种稳定可控的情绪是不同计数。底模的 caption 编码器可能理解训练七句之外的日语短句，但当前 LoRA 可能改变这种泛化，生产校验也会拒绝新短句。因此**不重训可以做隔离的零样本短句实验，但本轮证据支持的新增可辨识条件数量是未知，而不是预先承诺14或21种。**

不重训优先提升已有条件的准确选用，避免把 quiet→natural、bright→强烈快语、whisper→强气息这三组都当成同一物理强度轴。尤其最后一组同时改变发声方式、呼吸、距离和情境，不是天然可插值的弱/强两端。

| 不重训手段 | 原理判断 | 在本任务中的处理 |
|---|---|---|
| 固定caption调整CFG | 改变对完整描述条件的遵循，不是情绪幅度标尺 | 只做离线校准；不作为中间锚，不在线随intensity连续改变 |
| duration_scale | 本地 runtime 将预测帧数乘系数再裁到上下限；改变目标时长 | 可研究0.95/1/1.05，但只叫节奏变体；当前wrapper未暴露，不作为主方案或新增情绪控制 |
| 现有标点/自然句停连 | 文本影响韵律与分段 | 保留原文合法标点，不伪造“啊/哈”等音素，不靠大量碎切制造断续 |
| 新日语短句、未重训 | 编码器语义泛化可能有效 | 使用独立评测入口绕开生产请求而非放宽生产校验；过盲测才注册实验码本 |
| caption embedding插值 | 两段不同长度的条件序列无直接token对齐；混合点不保证在训练分布 | 不做本轮主线，也不满足“只以日语短句控制”的直接可审查口径 |
| `_z` 连续量 | dataset和模型目前不消费该字段 | 只用作待核验的离线样本排序；禁止新增数值控制接口冒充现成功能 |

CFG 更具体的依据是当前 `irodori_tts/rf.py`：independent 模式从全条件速度 `v_all` 出发，对每路叠加 `s_k*(v_all-v_drop_k)`；joint 是 `v_cond+s*(v_cond-v_drop_all)`。所以 caption scale 放大的是“含此caption”和“去掉此caption”的差，不是 `v_weak` 与 `v_strong` 的差。非线性积分之后也没有“CFG=3.5正好位于弱/强正中”的保证。CFG 原始方法同样通过条件与无条件预测组合调节质量/多样性，而不提供情绪单调性定理。[Classifier-Free Diffusion Guidance](https://arxiv.org/abs/2207.12598)。

大凤的 joint_cfg=4.5 会覆盖计划里的单独 caption cfg。其 CFG 扫描还同时作用文本/说话人，不能套别船结果。上游参数说明也区分各路引导与时长控制；本文具体行为以本地版本为准，不把上游 main 的新模型能力当成本机能力。[Irodori 参数说明](https://github.com/Aratako/Irodori-TTS/blob/main/docs/parameters.md)。

若未来获准测试“不重训是否有中间态”，采用同船8条文本×2个锚×3个caption CFG×2种子＝96次，固定其余变量；CFG用各族基准的0.85/1/1.15倍，仅独立引导船。对每个固定锚验证盲评分是否有可重复的顺序变化，不能将两锚混合后的总体趋势误认为单调。duration另做独立实验，不能同时扫而无法归因。即使通过，也只记作经校准的该船/该锚变体，不推广为通用情绪强度。

### 3.2 三维覆盖：从稀疏设计开始，不做全组合许愿

目标空间为唤醒度低/高 × 效价负/中/正 × 发声 voiced/soft/breathy/whispered。全积为24格，但并非每格都需要或容易获得可靠数据。第一轮成熟目录建议覆盖12格，所有caption为固定、短的日语句子，保持旧7句在旧版本目录逐字不动。

| 发声 | 唤醒/效价覆盖 | 日语候选例 | 格数 |
|---|---|---|---:|
| voiced | 低×负/中/正 | `沈んだ、静かな声で`；`自然な声で、丁寧に`；`穏やかで、温かい声で` | 3 |
| voiced | 高×负/中/正 | `苛立った、強い声で`；`驚いた、張りのある声で`；`明るく、弾んだ声で` | 3 |
| soft | 低×中/正 | `小さな声で、穏やかに`；`小さな声で、嬉しそうに` | 2 |
| breathy | 低×中/正 | `息を混ぜた声で、静かに`；`息を混ぜた声で、優しく` | 2 |
| whispered | 低×中/正 | `囁き声で、静かに`；`囁き声で、優しく` | 2 |

这些是待训练/听辨候选，格名只是采样设计，实际 A/V 由人标音频，不能从caption字面生成“真值”。负效价高唤醒的 soft/breathy/whispered 等尚未覆盖，应显示 unsupported；不声称12格等于完整真人表现。旧7句与新目录有重合，不能直接把7+12当作19种新的独立能力。

断续、气息不匀是时间组织，贴近是感知/声学距离；它们不是第五种效价或发声方式。先在一个中性效价基底上分别做第四问的对照，最多增加3个经验证组合，再决定哪些值得独立注册。禁止把每个轴的片段任意拼接为从未训练过的长caption。

### 3.3 最小可执行数据实验：先证明四个发声锚能分开

选阿尔比恩作为首船，因为当前 emo_spk 有83条、七锚都有记录且没有大凤的 joint 特例；这只是降低变量，不意味着它最易训练。

新锚固定四句：`小さな声で、穏やかに`（弱声）、`息を混ぜた声で、静かに`（有声气息）、`囁き声で、静かに`（耳语）、`息継ぎを挟み、途切れがちに`（呼吸停连）。每锚24条＝96条，同一组24种中性台词尽可能由同一音色录四种演绎；每条4–8秒，保留实际呼吸、正确文字和录音来源。

新录音必须真实包含目标发声。仅把83条旧录音复制四次换caption，不增加声学信息；由现有模型生成的“新耳语”也不能独立证明模型学到它原本不会的耳语。若无法获得目标船的真实/同身份有效样本，先从合法可用原音中筛选；不足则降低实验结论为“词义重标是否改善”，不能宣称已扩出新发声能力。借用别的声音只能作为跨说话人研究，需要正确speaker_id和额外身份回归，不能直接贴成阿尔比恩。

另外从现有83条选64条旧风格回放，保持原caption并覆盖七锚；旧新合计160条、按4–8秒估算10.7–21.3分钟，其中新增96条为6.4–12.8分钟。旧录音实际总时长本轮未计算，分钟数只是采样目标。

分组拆分：新24种台词按16/4/4分为训练/验证/封存，每种台词四个发声版本留在同一分区，因此新样本64/16/16；旧回放按源台词/录音去重后40/12/12；合计 **104/28/28**。如果旧回放与新台词重合必须整体重分；七锚稀有类优先保证训练中有真实样本，不能假称每个分区都可分层齐全。声学评测另用未训练中性台词，不能只拿这些训练音频做重建评分。

训练/验证 manifest 分开保存。当前 train.py 有 valid_ratio 路径，但不能仅设比例声称实现了上述组级拆分；实施时需增加显式验证 manifest 或离线训练入口，使分区确定且可核查。

### 3.4 小 LoRA 配置、初始化和停机条件

第一实验从**相同本地底模**训练新的 rank=8 adapter，旧 adapter 完整保留作基线，不叠加两套 LoRA。先使用 diffusion_attn，alpha=16，batch=1、accumulation=1、bf16、gradient_checkpointing=true、短音频离线预编码，学习率两档2e-5/5e-5、两个种子、每次最多600步，在200/400/600步保存并只用验证集选择。

新adapter不继承旧LoRA中的身份适配，可能退步，所以旧样本回放、固定speaker资产及旧adapter对照是必要条件。若首轮表明从头学身份太难，第二方案是复制旧rank16 adapter续训，保持rank16，重置优化器和step，不能在YAML里改rank=8就假称完成降秩。当前 `--resume` 会加载已有adapter并涉及训练状态；实施时需检查或增加“只初始化adapter权重”的实验选项，避免继承旧step导致训练不执行或学习率错位。

第一轮 `lora_modules_to_save: none`、`duration_loss_weight: 0`，明确打印并检查可训练参数只含预期LoRA层；speaker inversion不开，文本/说话人编码器保持冻结。LoRA原理通过低秩可训练更新减少需优化参数，并不保证身份不漂移，也不保证任意底模在8GB上都能训练。[LoRA论文](https://arxiv.org/abs/2106.09685)。

注意冻结duration会限制停连/总时长适应；如果前三种音质学会而第四种停连失败，再单独加一个duration开放对照，不能第一轮同时改所有条件。`auto`会带入完整duration_predictor，不是“保存一下无影响”。小实验warmup建议20–30步，使用匹配600步的调度，不能照搬现有warmup=1000、max_steps=200/500的设置。保留长句/普通语音回归，避免只优化短句。

训练前列出底模/codec/tokenizer/adapter配置和speaker资产哈希，验证输入长度、caption、speaker_id、分区以及模型配置一致；使用新输出目录，绝不覆盖生产checkpoint或修改ships.json。104条训练、600个batch=1优化步约为5.8次样本遍历；训练loss下降不意味着表达学会，可能只是记住台词。

未来实验若显存不足，先缩短目标/参考长度、确认没有其它模型共驻，降低rank只能节省部分优化器/参数内存，不能消除激活显存。不要为了跑通直接量化/换底模改变实验问题。当前服务需要持续运行而无独占GPU窗口时，训练任务应等待排期；本设计任务不停止服务腾卡。

### 3.5 RTX 5060 Laptop 8G 的工时如何给出可信数字

本轮没有训练测速，也未验证显存峰值。先安排100步短探针，舍弃前20步启动影响，测20–100步中位与P90的 **optimizer step** 耗时、峰值allocated/reserved、GPU总占用、是否OOM和热降频。不同累积步数必须重新测，不把microstep当optimizer step。

计算式：`GPU训练小时 = 运行次数 × 每次优化步数 × 实测秒/步 ÷ 3600`，另加编码、保存、验证合成时间。举例仅为预算情景：若0.5–3秒/步，4次×600步为0.33–2小时；100步探针另0.014–0.083小时；预编码/加载/验证假设0.5–1.5小时，则一船总预留约 **1–4 GPU小时**。若实际5秒/步，仅2400步就3.33小时，总预算需上调；若8GB无法稳定容纳，以上预算直接失效。不能引用上版历史“600步几分钟”作为本轮承诺。

首船成功后按船顺序做，五船同等试验规模粗预算 **5–20 GPU小时**，尚不含补录、清理、五船完整声学验收；各船数据与joint模式不同，不能机械承诺线性工时。人工采集/标注通常比训练更费工。

最小160条只证明4锚路线是否值得继续。要做三维12格的可用目录，建议每船每格30–50条真实且文本多样的样本，即每船360–600条，五船1800–3000条；每条4–8秒约每船24–80分钟。该量级仍是实验起点，不是“接近真人”的充分条件；接近真人必须通过跨文本、长上下文、声学自然度和身份连续性测试。

### 3.6 五船音色保护与验收

先按船独立新adapter与旧adapter对照，使用当前speaker embedding/reference，不做第一轮跨船共享情绪LoRA或线性合并。通用风格LoRA可能学习说话人、录音距离和情绪的混合特征；共享数据少时尤其容易串音色。不能用“speaker_id存在”代替音色漂移评测。

每船保留20条普通台词×2种子＝40个旧新配对项目，五船合计200个配对项目/400个音频槽；检查人声身份盲评、清晰度和现有七锚表现。若有本地speaker encoder可作为补充，但先用该船旧音频确定分布，不设跨船统一cosine阈值；耳语本来可能降低embedding相似度，需结合人听。

建议旧新5分身份评分平均下降不超过0.3、清晰度下降不超过0.2，且关键发声锚通过第二问辨识门禁；这些是预注册工程阈值。任一船失败只保留该船旧资产，不能以五船平均改善覆盖个别船明显漂移。上线候选仍要保存可回退的旧资产和原始manifest；本轮不做上线。

## 第四问：NSFW 场景最高优先级——训练可辨的发声方式

### 4.1 哪些日语短句最值得先训练

以下全部是**候选**，未证明哪个在当前五船最有效。优先选可在音频中直接标注的特征，避免把情境、距离、响度和情绪全部绑在一个形容词上。新短句不直接替换当前七句原文。

| 优先级/目标 | 完整日语caption候选 | 音素/韵律解释与对照 |
|---|---|---|
| P0 弱声 | `小さな声で、穏やかに` | 目标是较低发声努力和柔和起音，仍保留浊音周期与清晰元音；与普通voiced、音量缩小的普通语音分别比较 |
| P0 带浊音气声 | `息を混ぜた声で、静かに` | 元音中保留周期成分，同时增加气流噪声；与纯耳语分开，不能只学到录音底噪 |
| P0 耳语 | `囁き声で、静かに` | 低周期性音质、气流性辅音/元音仍保持可懂度；不要求低F0，因为稳定F0可能不存在 |
| P0 断续换气 | `息継ぎを挟み、途切れがちに` | 目标是短语间换气、较短呼吸组及非均匀停顿；保留正常音拍，不将每个字切成独立音频 |
| P1 气息不匀 | `息を乱しながら、短く区切って` | 呼吸组长短变化与发声/气息交替；和机械等距静音对照，需真实不均匀呼吸样本 |
| P1 贴近 | `近くで、そっと話すように` | 是近距离感知提示，可能涉及直达声比例、细微口部声与轻声，不等于必定耳语；避免把特定麦克风低频染色当身份 |
| P2 轻微不稳 | `声を少し震わせて、控えめに` | 仅在真实样本有轻微振幅/基频不稳定时注册；与强抖动、粗糙失真区分，耳语不用F0抖动做金标 |

四锚最小实验优先前三种音质加断续换气，因为现有码本最大的压缩就在这些维度。贴近与气息不匀在第一阶段额外采样做候选听辨，但不把未验证词组先发到生产。

`甘く`、`優しく`这类语用/感情色彩词可以描述温柔，却无法单独定义气声或停连；`近い距離で`也不等于breathy。现有较强气息锚同时绑定多种特征，对旧版保持原样，对新增训练则拆成可观察单项及少量组合。没有真实对应音频时，“更精确的日语词”仍无法凭空制造能力。

### 4.2 与日常对话能否共用

可以共用同一版本化日语caption目录。弱声用于安静环境、气声用于轻柔交流或疲惫、耳语用于不打扰别人、断续用于运动后换气；无需训练一个专门的“NSFW family”才能控制它们。场景语用影响选择概率，发声机制和speaker身份不因此改变。

训练时同一phonation应包含多个非露骨日常语境、效价和文本，且同一日常文本尽量有普通voiced对照，防止模型靠关键词而不是caption学会风格。初期每个确定组合只用一种精确写法，不随机加多个日语近义句分散160条小集的监督。成熟后再验证近义泛化，仍由编译器输出注册的完整短句。

选择代价建议“日常误进强气息”高于“模糊场景暂时保持弱声”；NSFW高权重体现在该场景真实目标的召回与层次辨识率，而不是降低所有句子的亲密触发门槛。产品内部可保留context用途信息，但送给TTS的仍只有具体发声短句。

### 4.3 怎么验证气息有层次而非只是更吵

对同台词先比较voiced/soft/breathy/whispered，再对同breathy音质比较规则换气与不匀换气；最后比较日常与目标场景的语用自然度。音量匹配后仍能分辨音质，才排除“只是变小声/变大声”。保留原音量评估弱声效果，防止音量匹配把目标本身消掉。

音频不要用强降噪把呼吸擦掉，也不手工插入合成噪声冒充模型学会气息；推理尾裁剪须对照保留尾部气息版本。近距离感要靠真实录音与盲评确认，不能仅靠加低频或混响参数偷换目标。全句caption能控制整体倾向，但不能保证在指定词后换气；需要精确位置时，只利用现有自然子句边界与已标注对应样本，不承诺帧级控制。

## 风险与不做的事

- **标签定义风险**：family混合情绪与语用，气声不等于亲密。用target/route双标注和coverage_gap避免假准确率；不在小集上训练大分类器或新正则瀑布。
- **相关证据风险**：LLM、译文和标点同源；去重、来源预算、缺失不重归一化，防止过度自信。明确中性与“没有信号”区分。
- **时序风险**：当前子段与自然句不等价；幂等提交、完整句计数、取消/换船重置必须测试。设计不阻塞等待未来句，不追改已播音频。
- **覆盖风险**：七锚没有纯气声/纯耳语/断续的充分分离监督；更多参数组合不代表更多可听辨条件。`_z`未进入模型，不能把写JSON当成连续控制。
- **数据风险**：307行是清单数，32条气息相关也不是32条高质量纯目标样本；需听辨、去重、按音频来源拆分。不能把改caption、复制样本或同模型自合成当真实扩锚。
- **身份与时长风险**：LoRA可以带偏音色，auto可能训练duration；先独立船、冻结大部分模块、旧样本回放和盲评。新rank8从底模训练与rank16续训是两种实验，不混用配置解释。
- **资源风险**：8GB能否装下新实验及每步耗时未测；训练必须未来独占GPU窗口。不启动第二个常驻模型，不在当前服务旁强行训练，不自动升级底模/库。
- **评测风险**：200条支持发现大问题，不支持宣称接近真人或微小胜率；单人听感仍有人为偏差，以隐藏重复、声学佐证与明确分母降低风险，不使用外部标注服务。
- **范围约束**：本轮不改任何生产文件、不重启、不GPU合成、不训练、不push。文中实施文件、门槛、训练量与新caption全部为待验证设计，不是已完成能力。
