## 1. 一句话版本

```
每 60 秒醒一次 → 看他刚才有没有说话 / 到点没 / 摄像头里有没有人
              → 都没问题就塞一句括号旁白进她的会话
              → 她自己接着说话（可能还自己决定看一眼屏幕）
              → 等不到回应就一次比一次等更久，连续 3 次就闭嘴
```

---

## 2. 谁在跑（只有一份）

- 代码：`albion-pet.ts` 里的 `setInterval(() => { … }, 60_000)` ✓ —— **每分钟一次** ✓
- 只在**leader 窗口**执行（同一份"对外副作用"逻辑不允许多窗口各跑一遍 ✓）
- 三个闸门写在 localStorage（跨窗口/跨重启共享）：
  | 键 | 作用 |
  |---|---|
  | `settings/albion/proactive-last-at` | 上次开口的时间戳，**90 秒内只允许一次** ✓（防 HMR / 重载 / 多实例连发；9-17 实测出现过 11 秒两条一模一样的）|
  | `settings/albion/proactive-minutes` | 基础间隔（分钟）✓ **每轮实时读** ⇒ 改完不用重启壳 ✓ |
  | `settings/albion/proactive-jitter` | 抖动比例，默认 `0.5` ⇒ 每轮乘数落在 ×0.5 ~ ×1.5 ✓ |

## 3. 一次开口的完整判定（从上到下，任何一步不过就等到下一分钟）

```
① proactive-minutes <= 0 ?            → 直接不启用（关掉主动消息就把它设 0）✗
② 他说话了？(会话消息数变了)           → 是：结束静默、清零计数、awayStreak=0、重新计时 ✓
③ 还没到 waitUntil？                  → 是：这次什么都不做 ✓
④ silentStreak >= proactive-silent-max → 是：进静默，只把它 30 分钟后再看一次（不开口）✗
⑤ 上次开口不到 90 秒？                 → 是：跳过 ✓（防重复）
⑥ 摄像头里没人？(只在 eyes-enabled 时问) → 是：awayStreak+1，这次不开口 ✓（不打扰空房间）
                                        → 看不清 / 没摄像头：照旧开口 ✓
⑦ 以上都过 → 写 last-at → 置 awaitingReply → 塞旁白 → 按 silentStreak 排下次
```

对应代码（摘）：

```ts
if (msgs.length !== lastSeenCount) {        // ② 他说话了
  lastSeenCount = msgs.length
  if (awaitingReply) { awaitingReply = false; silentStreak = 0 }
  awayStreak = 0
  waitUntil = Date.now() + nextWaitMs(0)
  return
}
if (Date.now() < waitUntil) return          // ③
if (silentStreak >= maxSilent) {            // ④ 静默中
  waitUntil = Date.now() + 30 * 60_000      //    半小时后再看一眼；他一开口就恢复
  return
}
if (Date.now() - Number(lastAt) < 90_000) { waitUntil = Date.now() + 60_000; return }  // ⑤
if (eyesEnabled()) {
  const here = await eyesPresence()
  if (here === false) { awayStreak = Math.min(awayStreak + 1, 99); return }             // ⑥
  awayStreak = 0
}
await sendPoke(`（${hint}）`)                    // ⑦
waitUntil = Date.now() + nextWaitMs(silentStreak)
```

## 4. 塞进去的那句话（措辞是刻意这么写的）

```ts
const hint = `这是我自己心里冒出来的念头，不是谁在跟我说话，也不用当成一条要回的话：
屋里安静好一会儿了。想说什么、要不要看一眼，都由我自己定；
要是只想陪着、不想出声，就把整段都写进括号里（括号外不要留正文）——
那样不算半吊子回话，就是静着陪。${eyesEnabled() ? LOOK_HINT : ''}`
await sendPoke(`（${hint}）`)
```

四个讲究：

1. **主语是「我」** —— 她读到就像自己想到的，不会误认成"指挥官在提醒我" ✓
   （9-18 之前写的是"外面有人在吩咐她"，读起来像有人在指挥她 ⇒ 已改掉 ✓）
2. **不强迫**："想说什么 … 都由我自己定" ⇒ 她可以选择不说、也可以选择看一眼 ✓
3. **外层的「（…）」= 旁白标记** ✓ —— 你打的字**不带括号** ✓，一眼能分清
4. **（2026-09-21 加）"不想出声"要说全** ✓ —— 规则本来是「**括号里 = 只显示不朗读** ✓ /
   **括号外 = 朗读** ✓」（`bridge.py:59` + 跨请求状态机 `strip_asides_streaming`）。
   但她会把场景写进括号、把"只是陪着"写成**正文** ⇒ 那句就被念出来，
   听起来像在对谁回话 ✗（"……不出声。"还被念出声 ✗）。
   所以明说：整段不想出声就**整段写进括号**、括号外不留正文 ✓；
   并补一句**那样不算半吊子回话**（她人格里有 "Don't send half-baked replies." ✗
   否则她会觉得只写心声 = 失职）✓
   实测改前 6 次主动开口里 3 次自发这么收尾 ✓ —— 把话说全是为了稳 ✓
   （她"看"完图之后，会话里也会**再多一条**括号消息 = 壳把画面结果塞回去 ✓
   两条括号是**两个不同的自动注入** ✓：一条叫她开口、一条给她画面 ✓）

### 她要不要看、看哪一路 —— 她自己决定

- 壳**不再**替她挑来源 ✓；她想要就在回复里写 `<|LOOK:his|>` / `<|LOOK:mine|>` / `<|LOOK:cam|>` ✓
- 壳取来图（走视觉模型转述）→ 再用一条括号旁白回给她 ✓
- `his` = 指挥官那台的屏幕 · `mine` = 她所在那台的屏幕 · `cam` = 本机摄像头

## 5. 频率：公式与实测值

```ts
nextWaitMs(round) = base × jitter(0.5~1.5) × 2^min(round, 3) × slowFactor()
```

- `base` = `proactive-minutes`（**现值 25 分钟** ✓）
- `round` = 当前静默计数 ⇒ **没回应就 ×2 / ×4 / ×8（封顶 ×8）**
- `slowFactor()` = `rateFactor()`（`albion-proactive-rate.ts`，纯函数、有单测 5/5 ✓）：
  ```ts
  rateFactor = (在夜里 ? quiet-factor : 1) × awayFactor(awayStreak, away-cap)
  inQuietHours('00:30-09:00')  // 支持跨零点；空串 = 不启用
  awayFactor(n, cap) = min(1 + n, cap)   // 他不在 1 次 ×2、2 次 ×3 … 封顶
  ```

**现值与实际间隔**

| 情形 | 系数 | 实际间隔 |
|---|---|---|
| 白天、摄像头看得见他（**现在就是这样** ✓）| ×1 | **12.5 ~ 37.5 分钟** |
| 白天、他不在（摄像头没人）| ×2 → ×6 | 25 ~ 225 分钟 |
| 夜里 00:30–09:00、他在 | ×4 | 50 ~ 150 分钟 |
| 夜里 + 他不在 | ×4 × 6 = ×24 | **≈5 ~ 10 小时**（基本到天亮）|

再叠上"没回应退避（×2/×4/×8）"与"连 3 次没人理 ⇒ 静默（每 30 分钟只看一眼、不开口）" ⇒ **实际只会比表里更安静** ✓。

**实测样本**（她库里的真实开口时间）：改前 6~19 分钟一轮；改成 25 分钟基础后，13:43 上线只开口 **1 次**（14:15，距上次 **44 分钟** = 25 × 抖动 × 静默退避 ×2 ✓），之后长时间不吭声 = 进了静默 ✓；最近一次 **21:09** ✓。

## 6. 设置键总表（都在 localStorage `settings/albion/` 下）

| 键 | 当前值 | 含义 |
|---|---|---|
| `proactive-minutes` | `25` ✓ | 基础间隔；**0 = 完全关掉主动消息** ✓（实时生效）|
| `proactive-jitter` | `0.5` | 抖动比例 |
| `proactive-silent-max` | `3` | 连续几次没人理就进静默 |
| `proactive-quiet-hours` | `00:30-09:00` ✓ | 睡觉时段（空串 = 不启用）|
| `proactive-quiet-factor` | `4` ✓ | 睡觉时段的倍数 |
| `proactive-away-cap` | `6` ✓ | "他不在"倍数上限 |
| `proactive-last-at` | 时间戳 ✓ | 上次开口（观测用）|
| `eyes-enabled` | `1` ✓ | 要不要用摄像头判断"他在不在" |

## 7. 怎么观测 / 怎么排障

**看它活着没**：读 `settings/albion/proactive-last-at`（会随时间往前走 ⇒ 说明定时器在跑 ✓；现在这个值对应 **21:09** ✓）。

**看她真开口了没**：去她的会话库里找**带括号**的消息（那才是自动注入；你打的字不带括号）✓。

**日志**：壳的 console 里有 `[albion-pet]` 前缀的行，例如
`摄像头里没人（他大概出去了），这次不开口，下次间隔再拉长` ✓、
`距上次主动开口不到 90 秒，这次跳过` ✓。

| 现象 | 真因 | 怎么办 |
|---|---|---|
| 一直不主动说话 | ① 进了静默（连 3 次没人理）② 摄像头认为没人 ③ 正在夜里时段 ④ `proactive-minutes=0` | 你先跟她说一句话 ⇒ 静默与计数**立刻清零** ✓ |
| 说得太勤 | `proactive-minutes` 太小 / 抖动太大 | 把 25 调大（实时生效，不用重启壳）|
| 完全不想让它开口 | — | `proactive-minutes = 0` ✓ |
| 她主动开口但没声音 | 那是**两条链路**：主动消息只管"发起对话"，出声要走 TTS（见《阿尔比恩TTS全流程》）| 检查 `9889` / `9881` |
