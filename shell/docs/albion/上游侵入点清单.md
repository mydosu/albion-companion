# 上游侵入点清单

本 fork 改过的上游 AIRI 文件逐个列出：改了什么、为什么改、以后同步上游时怎么处理。
阿尔比恩专属的新文件不会和上游冲突，只在第二节按目录列一遍。

- 盘点日期：2026-10-21（S7-a；含 S5 托盘与窗口改动、S7-b 搬家后的路径）。
- 上游基线：`moeru-ai/airi` 的 `v0.12.0-beta.5`（2026-08-30）。
  判断依据：壳的 `package.json` 版本号相同；拿该 tag 的文件树比对，`apps/`、`packages/` 下只多出 50 个源文件，全是下面列的新增文件。
- 统计范围：`shell/` 下和基线 blob 不同的文件，共 125 个（含测试、锁文件、配置）。
  其中 7 个和上游最新 `main` 完全一致，是后来从上游回移的改动（见第四节）。

## 处理方式说明

| 标记 | 含义 |
| --- | --- |
| **重放** | 改动小且集中，同步后在新版上游文件里照原样再改一次 |
| **收拢** | 改的是上游默认值或入口接线。入口接线已收进 `albion/albion-stage-bridge.ts`；阿尔比恩默认值以 `albion/albion-defaults.ts` 常量作 store 初始值，重置回阿尔比恩默认（见下方“S7-c 结论”），同步时保留这些一行改动 |
| **手工合并** | 改动大、上游同一处也在变；要对照两边逐段合，合完跑对应测试 |
| **取上游** | 我们拿的就是上游后来的版本，同步时直接用上游的 |
| **再裁剪** | 我们删掉的上游功能，同步后再删一次 |

## S7-c 结论（2026-10-22）

- **已收：Stage 钩子。** 情绪入口（`globalThis.__albionStageEmotion`）和本机流式 TTS 的会话参数，从 `Stage.vue` 挪进 `albion/albion-stage-bridge.ts`。`albion-pet.ts` 仍读同一个全局名，契约不变。
- **已定：重置回阿尔比恩默认。** 决定（调度，2026-10-22）：`resetState()` 之后回到 `albion/albion-defaults.ts` 里的阿尔比恩默认，不回上游默认。
- **做法：默认值不做启动时播种。** consciousness、speech、hearing、vision、stage-model 等 store 把 `albion-defaults.ts` 的常量直接作为 `useLocalStorageManualReset` 的初始值，`reset()` 写回的就是这些常量，重置路径本来就取阿尔比恩值。`applyAlbionDefaults()` 只写两个引导键（`onboarding/*`），不写业务默认值。因此没有「启动播种再同步 ref」的重置路径问题。
- **验证：** `stores/settings/stage-model.test.ts` 新增 `resetState restores the Albion default stage model`，改成自定义模型后重置，断言回到 `ALBION_STAGE_MODEL_ID`。
- **仍是上游字面量的默认值**（如 `language: ''`、`artistry-provider: 'none'`）：这些 Albion 没有改过，上游默认即阿尔比恩默认，重置结果一致。以后若要给它们换成阿尔比恩值，需要在 `albion-defaults.ts` 加常量并把 store 初始值改为引用它，同时补重置测试。

## 六、怎么维护这份清单

- 新改一个上游文件时，在第三节对应表格补一行；改动挪进新增文件后，把那一行删掉或改成“只剩接线”。
- 重新盘点（需要联网拉上游文件树，不拉文件内容）：

  ```powershell
  git clone --filter=blob:none --no-checkout --depth 1 https://github.com/moeru-ai/airi $env:TEMP\airi-upstream
  git -C $env:TEMP\airi-upstream fetch --filter=blob:none --depth 1 origin tag v0.12.0-beta.5
  # 用 git -C $env:TEMP\airi-upstream ls-tree -r v0.12.0-beta.5 的 blob 哈希，
  # 和 git ls-tree -r HEAD shell 逐个比较：哈希不同 = 改过的上游文件，上游没有 = 新增文件
  ```
- 真要同步上游时，按本表从“取上游”“再裁剪”“重放”到“手工合并”的顺序处理。Stage 钩子已经收进 `albion/albion-stage-bridge.ts`，默认值的处理见上面的 S7-c 结论。
