# 文件与目录说明

本仓库是 [Project AIRI](https://github.com/moeru-ai/airi) 的 fork，只保留「阿尔比恩桌宠」用得到的那部分：
上游的其它 app（`component-calling`、`stage-pocket` 等）已经删除，所以**改动的文件数看起来很多，实际大部分是删除**。
想看这个 fork 做了什么，读 [`ALBION.md`](../../ALBION.md)（功能说明）和本文件（文件地图）。

## 一、我们新增/改写的东西

### 壳（Electron 应用 `apps/stage-tamagotchi/`）

| 路径 | 是什么 |
| --- | --- |
| `src/main/services/airi/albion-sidecars.ts` | 壳启动时按顺序拉起本地语音服务（TTS/STT/对话后端），退出时收拾干净 |
| `src/main/windows/chatbox/index.ts`<br>`src/renderer/pages/chatbox.vue` | 聊天小窗：一个独立窗口，用来跟助手对话 |
| `src/main/index.ts`、`src/main/tray/index.ts` | 接入上面两个：启动流程、托盘菜单 |
| `src/main/windows/caption/index.ts` | 字幕/气泡窗口的改动 |
| `src/renderer/main.ts`、`src/renderer/pages/index.vue` | 渲染进程入口与主页面 |
| `src/renderer/public/albion-interactions.json`<br>`src/renderer/public/albion-motions.json` | 交互/动作数据（**见第三节的待确认项**） |
| `src/renderer/public/models/silero-vad/onnx/model.onnx` | 语音活动检测（VAD）模型，2.2 MB，已随仓库分发 |

### Spine 3.8 渲染器（`packages/stage-ui-spine/`）

这是本 fork 新加的一条渲染链路，和原有的 Live2D 链路**完全分开**（独立场景、独立设置键 `settings/spine38/*`）。

| 路径 | 是什么 |
| --- | --- |
| `src/components/scenes/spine38/Model.vue` | **渲染器主体**：加载 zip、纹理、视图变换（视角拖拽/缩放）、命中判定、待机分层播放、姿势播放、控制器叠加、语音口型、调试出口 |
| `src/components/scenes/spine38/author-engine.ts` | **作者格式的运行时**：直接执行模型作者 `modelN.json` 里的 `hit_areas` / `motions` / `var_floats` / `command` / `post_command` / `choices`，不自己发明交互语义；文件末尾带不依赖渲染器的自检 |
| `src/components/scenes/Spine38.vue` | 场景外壳：台词气泡 + 作者菜单（`choices`）的渲染与点击 |
| `src/components/scenes/index.ts`、`src/index.ts` | 把新场景注册进去 |
| `src/assets/author-models/` | **第三方资产，不进仓库**（作者的 json 与语音），见第三节 |

### 桌宠对外接口（`packages/stage-ui/src/albion/`）

阿尔比恩专属模块都集中在这个目录（2026-10-21 从 `src/`、`src/stores/`、`src/composables/` 搬来，行为不变），
包外通过 `@proj-airi/stage-ui/albion/<文件名>` 引用。

| 路径 | 是什么 |
| --- | --- |
| `albion-pet.ts` | 桌宠对外的统一接口（动作、情绪、命中区域查询、发送消息），壳和网页版都走这里 |
| `albion-interactions.ts` | Live2D 侧的交互层（命中区域 → 动作/台词） |
| `albion-interaction-owner.ts` | 一次启动所拥有的定时器与清理函数，停止时一起收回 |
| `albion-defaults.ts` | 本 fork 的默认配置值 |
| `albion-stage-bridge.ts` | Stage.vue 与阿尔比恩的接口：情绪/ACT 入口挂载（`__albionStageEmotion`，带 face/motion/hold）、哪些渲染器的 ACT 归 albion-pet（`isAlbionActRenderer`）、本机流式 TTS 的会话参数 |
| `albion-act.ts` | 回复里 `<\|ACT {...}\|>` 表演元数据的匹配与显示时剥离 |
| `albion-drafting.ts`、`use-albion-draft-activity.ts` | 指挥官是否正在任一窗口打字（跨窗口同步），打字时主动消息的“门铃”不响 |
| `*.browser.test.ts` | 上面模块的浏览器测试 |

改上游文件时动过哪些地方、同步上游时怎么处理，见 [`上游侵入点清单.md`](./上游侵入点清单.md)。

### Live2D 侧（`packages/stage-ui-live2d/`）

`components/scenes/live2d/Model.vue`、`composables/live2d/fit-model.ts`、`stores/view-control.ts`、`utils/opfs-loader.ts`、`utils/live2d-opfs-registration.ts`
—— 取景/缩放、模型加载（OPFS）、自定义模型选择相关的改动。

### 其它被打通的接线

`packages/stage-ui/src/components/scenes/Stage.vue`（场景容器）、`stores/display-models.ts`、`stores/modules/*`（听觉/说话/意识等模块开关）、`stores/providers/config.ts`、`stores/chat.ts`、`stores/modules/airi-card.ts`、`packages/stage-pages/.../settings/*`（设置页）、`apps/stage-web/src/main.ts`（网页版也接同一套）。

## 三、第三方资产（**不随仓库分发**）

| 路径 | 是什么 | 状态 |
| --- | --- | --- |
| `packages/stage-ui/src/assets/spine/` | 《碧蓝航线》阿尔比恩 Spine 3.8 模型（约 11 MB：骨架 / 图集 / 贴图） | 已在 `.gitignore`，需自备 |
| `packages/stage-ui-spine/src/assets/author-models/` | 模型作者的 `modelN.json`（交互规格）与 16 条语音 wav | 已在 `.gitignore`，需自备 |
| `packages/stage-ui/src/assets/live2d/` 下的模型 | Live2D 模型与贴图 | 上游的 `.gitignore` 规则已忽略 |
| `.tmp-spine-probe/` | 本地调试探针（非源码） | 已在 `.gitignore` |

**已知情况**：`apps/stage-tamagotchi/src/renderer/public/albion-motions.json`（759 KB）与 `albion-interactions.json`（14 KB）
是 Live2D 模型**自带**的描述数据（`Version: 3` 格式，含 `Idle` / `Idle#1` 动作组与参数名单），不含贴图与音频。
按「第三方资产不进仓库」的口径，它们本该一并移出；但它们**已经随 v1.0.0 公开过一次**，删除只影响后续 clone。
