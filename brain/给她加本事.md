# 给她加本事 —— 这份东西怎么长

阿尔比恩的脑现在**长在 Pi 自己身上**。宿主（`bin/server.py`）只剩协议转接，
所有"她会怎么说话、记得什么、不许说什么"都在 `agent/` 里，改完**下一轮自动生效**
（宿主每次收请求比对 `agent/extensions/*.ts` 的目录签名，变了就换一具新身子，历史由壳每轮重发，不会失忆）。

## 一、东西都放在哪

| 想改什么 | 改哪里 | 生效方式 |
|---|---|---|
| 她是谁、什么脾气（人格） | `agent/SOUL.md` → 启动时生成 `agent/SYSTEM.md`（**别手改 SYSTEM.md**） | 重启脑 |
| 她长期该记住的规矩/边界 | `agent/APPEND_SYSTEM.md`（每轮都附在系统提示后面） | 下一轮 |
| 只在某类事上用的做法（干活、讲功课、给自己写扩展） | `agent/skills/<名字>/SKILL.md`（Pi 原生技能，系统提示里只放名字和"什么时候用"，用到才读） | 下一轮（也算进换身子的签名） |
| 每轮说话约定、回忆注入、活动库 | `agent/extensions/albion-turn.ts` | 存盘即换身子 |
| 说话整理器（补 ACT 竖线、心声收括号、太密的陪伴模板句拿掉；不叫模型、不打回重说） | `agent/extensions/albion-guard.ts` | 存盘即换身子 |
| 模型通路（本机转发，绕开上游建连超时） | `agent/extensions/albion-relay.ts` | 存盘即换身子 |
| 记忆读写（OpenViking） | 召回：`albion-turn.ts` ↔ `bin/memory.py`；捕获与 `openviking_*` 工具：`agent/extensions/openviking.ts`（官方扩展薄壳） | 存盘即换身子 |
| 派活儿给子进程 | `agent/extensions/delegate.ts` | 存盘即换身子 |
| 她自己造的工具 | `agent/extensions/*.ts`（新文件） | 存盘即换身子 |
| 上哪个模型、哪个上游 | `agent/models.json` | 重启脑 |
| Pi 自身设置（默认模型、思考档、图片不缩） | `agent/settings.json` | 下一轮（宿主把它和 `APPEND_SYSTEM.md` 也算进换身子的签名） |
| 她平时的家（书、便条、游戏） | `/root/家` | 不是代码 |

## 二、加一件新本事的三条路（从懒到狠）

**1. 她改自己要说的话 —— 改 `APPEND_SYSTEM.md`（最省事）**
一段中文说明，下一轮就生效。适合"以后别这样/记得这样"。

**2. 她要能调外面的东西 —— 写一个扩展（八成够用）**
在 `agent/extensions/` 新建一个 `.ts`，形状就两种，抄现成的：

```ts
// 形状 A：给自己加一件工具（抄 grab-page.ts / delegate.ts）
import { Type } from "typebox";
export default function (pi: ExtensionAPI) {
  pi.registerTool({
    name: "my_tool",
    description: "一句话说清它干什么、什么时候用",
    parameters: Type.Object({ arg: Type.String({ description: "…" }) }),
    async execute(_id, params) {
      // 想调外部命令就用 pi.exec()；想查数据库/调模型就在这儿写
      return { content: [{ type: "text", text: "结果" }] };
    },
  });
}
```

```ts
// 形状 B：改她这一轮看到/说出的话（抄 albion-turn.ts / albion-guard.ts）
export default function (pi: ExtensionAPI) {
  pi.on("context", async (event) => ({ messages: /* 改写后的 messages */ }));
  pi.on("message_end", async (event) => ({ message: /* 替换定稿消息 */ }));
  pi.on("tool_call", async (event) => { /* 看/挡工具调用 */ });
}
```

**3. 她要一套自己的算法 / 已有 Python 逻辑 —— 扩展 + 一个 Python 小命令**
别把已经调好的逻辑重写一遍：让它 `pi.exec()` 调 `python3 /root/albion-pi/bin/xxx.py --step ...`，
stdin 收 JSON、stdout 出 JSON（`bin/memory.py`、`bin/voice_tidy.ts` 就是这个形状）。
一份逻辑一个源，扩展只当"钩子"。

## 三、自己动手时的五条规矩

1. **一次只加一件**，存完先跑 `node bin/check_extensions.ts`。换身子是整批加载：**一个扩展坏了，整批都起不来**，那一轮她就说不出话；
   `parameters` 写成普通对象本地不报错、上游回 400，这个检查也一并查。
2. **先读文档再写**：`/usr/local/lib/node_modules/@earendil-works/pi-coding-agent/docs/extensions.md`，
   例子在同级 `examples/extensions/`。别凭印象编 API。
3. **扩展里的钩子是"每轮"发生的**，要快、要能失败：任何外部调用都要有超时，出错只记日志，绝不能把这一轮搞死。
4. **别碰**：`albion-guard.ts` 的整理规则（唯一源）、`bin/server.py` 的协议转接、`:8650`/`:8798` 上自己那个进程。
5. **要库就装库，外网不通就换路**（2026-10-14：她为查农历反复 curl 一个连不上的接口，被复读守卫停掉、一句话没说）。
   本机能算的（农历节气、日期换算……）先找现成的库；装在 `agent/extensions/` 里，走国内镜像（本机直连 npmjs 不通）：
   `npm install <包名> --registry=https://registry.npmmirror.com`。外网接口直连不通就加 `-x http://127.0.0.1:7897` 试一次，
   还不通就换做法，同一个地址别反复试；做不成就照实说卡在哪。

## 四、加完之后怎么验

```bash
node bin/check_extensions.ts           # 扩展整批能不能加载、工具形状对不对（不叫模型，几秒）
node bin/test_loopguard.ts             # 复读断路/坏工具/快照账本自检
node bin/test_guard_ext.ts             # 说话整理器与每轮约定自检
bash /root/albion-pi/accept.sh          # 直接跑 pi 就应该是她：人格/记忆/整理器/两个壳入口，全套
python3 bin/test_brain.py               # 端到端（经宿主）
```
扩展换了之后，若 `accept.sh` 里"她说的话"变了味，先看 Pi 的 stderr（桌面会话在 `/root/albion-pi/logs/pi-albion-desktop.err`，accept 等其它会话在 `/tmp/albion-pi-err/pi-<会话>.err`），
再看 `state/last-context.json`（这一轮到底注入了什么）——**别猜，看凭据**。
