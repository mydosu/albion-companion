# 09 她的眼睛：截屏和摄像头，谁能看到什么

目标：她想看我的屏幕，或者想看一眼屋里有没有人，自己能去看，不用等我贴图；但屏幕上的密码不能被她（或者她背后的模型）看到，摄像头拍到的我也不能出这个家。

这一块的主线跟 08 一样：**一开始是壳替她看，最后是她自己看，壳什么都不管**。中间的坑大多不在截图本身，在于「谁来取、取到的图交给谁」。

## 整体怎么搭的

```
主力机（Windows）                         阿尔比恩所在的电脑
 capture_agent.py :8790  <── HTTP+token ──  脑（WSL）albion-look.ts：工具 look(target)
   /health  /shot  /cam                       ├─ his   主力机屏幕   ┐ 原图交主模型
                                              ├─ mine  本机屏幕     ┘ （主模型不收图 → 转给别的模型写成文字）
 阿尔比恩所在的电脑上还有一份 :8790             └─ cam   本机摄像头   → 只交局域网里的本地视觉模型，她拿到文字
```

两头各管一件事：

| 一头 | 在哪 | 管什么 |
|---|---|---|
| 采集端 | `pet/tools/eyes/capture_agent.py` | 被问才截一张图、涂黑敏感的东西、返回 JPEG。别的什么都不做 |
| 脑里的工具 | `integrations/pi-brain/agent/extensions/albion-look.ts` | 她调 `look`，它去采集端取图，决定这张图交给谁看 |

采集端装两份：一份在阿尔比恩自己这台（`--bind 127.0.0.1`），一份在我日常用的主力机上。她的 `mine` 取前一份，`his` 取后一份。

## 采集端：只做一件事

只用标准库加 Windows 自带的 .NET（`System.Drawing`），不用 pip 装任何东西。截屏是启动一个 PowerShell 跑 `CopyFromScreen`，存成 JPEG 再读回来。

| 接口 | 要 token | 返回 |
|---|---|---|
| `GET /health` | 不要 | `{"ok": true, "screen": "宽x高"}`——它会真截一张 320 宽的图，证明「真能截到」，不是光进程活着 |
| `GET /shot` | 要 | 多显示器拼在一起的整屏 JPEG |
| `GET /cam` | 要 | 摄像头一帧 JPEG |

### 门：token

- 请求头 `Authorization: Bearer <token>`，用 `secrets.compare_digest` 比。
- token 从文件读（`--token-file`，取第一行非空内容），**不进命令行**。`--token <值>` 也能用，但值会出现在进程列表里，所以启动器都不用它。
- **文件缺失或为空，采集端直接不起**，不会悄悄换成随机 token。换成随机的话，进程活着，脑那边却全是 401，很难看出问题在哪。现在宁可明明白白起不来。
- 日志不记查询串，错误响应里没有 token。

### 地址：默认只绑 Tailscale

不绑 `0.0.0.0`，只绑本机的 Tailscale 地址（`tailscale ip -4`）。

开机时 Tailscale 常常比采集端晚一步起来。早期版本取不到地址就退回 `127.0.0.1`，而脑那边配的是 Tailscale 地址，于是跨机取图一直失败，没有任何东西会来纠正。现在是**等**：没给 `--bind` 就最多等 10 分钟，等到再绑，等不到才退回 `127.0.0.1` 并明确打一行警告。

### 加 `--lan`：Tailscale 走中继的坑

两台机器在同一个局域网，我却发现一张整屏要 **35 到 60 秒**。原因是主力机开着系统 VPN，Tailscale 打不了洞，流量绕到海外的中继节点。局域网直连只要 1 到 3 秒。

办法是照 Mouse Without Borders 的做法：`--lan` 时**再多绑一个本机的局域网地址**。只认 `10.0.0.0/8` 和 `192.168.0.0/16`——`172.16/12` 多半是 WSL、Hyper-V 的虚拟网卡或 VPN，`169.254` 是没拿到地址的网卡，都不绑。token 照旧是门。

脑那边配合：`ALBION_EYES_HIS_URL` 可以写好几个地址，逗号分隔，局域网的写前面、Tailscale 的写后面。每次取图前对地址依次做 3 秒的 TCP 探测，挑第一个通的；都不通就用最后一个。

### 取图前先涂黑

这一步在采集端做，不在脑里：**交给谁看的，都已经是涂过的图**。

1. 顶层窗口的标题或进程名命中关键词（`password`、`登录`、`验证码`、`keepass`、`钱包`、`无痕` 等一串），整个窗口涂黑。
2. 用 UI 自动化找出系统报出来的所有密码输入框，单独涂黑。比第 1 条准，整个桌面扫一遍约 250 毫秒。

做不到的是「看不出是密码框的普通输入」，比如某个程序自己画的密码框，那种只能靠窗口标题命中。

涂黑**失败了就不出图**：UI 自动化不可用、超时、输出不完整，`/shot` 一律返回 500，不会退化成「没涂黑也给你」。

### 踩过的坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 她取图报「采集端 500」 | 截屏和 ffmpeg 抓帧都不能并发，两路撞在一起后者失败 | 一把进程级的锁，第二路排队等，截图和摄像头共用 |
| 截出来的图是缩小的，窗口坐标也对不上 | 进程不是 DPI 感知的，`VirtualScreen` 被系统虚化（真屏 1200×1920 只截出 960×1536） | 截图前调 `SetProcessDPIAware()`，按物理像素算 |
| 每次取图桌面弹一个黑框 | 每次起 PowerShell、ffmpeg 子进程都带窗口 | 子进程统一 `CREATE_NO_WINDOW` |
| 截屏一路 500 直到重启 | 脚本写在临时目录，被系统清理掉了 | 每次用之前检查文件在不在，不在就重写 |
| 取完的图留在磁盘上 | 进程被强杀，没来得及删 | 图取完就删；启动时只扫一遍超过 1 小时的旧残留，不做定时任务 |

## 摄像头

同一个进程管摄像头：`/cam` 用 ffmpeg 通过 DirectShow 抓一帧，先转正，再按 `--max-width` **只缩不放**。

- **画面是歪的**。我的摄像头是侧着装的，原始画面里人头朝左。本地的 4B 视觉模型把它认成「倒的、白花花一片」。顺时针转 90° 才是正的，所以默认转 90°，换了摄像头朝向就改 `--cam-rotate 0/90/180/270`。
- 转完是竖的，只有 1080 宽。早期我写的是 `scale=1920:-1`，会把它放大到 1920×3413，纯属浪费，改成只缩不放。
- 摄像头名字（`FHD Camera`）和 ffmpeg 路径是写在 `capture_agent.py` 开头的常量，换设备要改代码，没做成参数。

## 脑里的 `look`：谁能看到什么

她有一个工具 `look(target)`，`target` 是 `his`、`mine`、`cam` 三选一。取回来的图怎么处理，是这篇里我花心思最多的地方：

| 路 | 图交给谁 | 她拿到什么 |
|---|---|---|
| `his`、`mine`（屏幕） | 主模型自己看原图 | 一张图 |
| `his`、`mine`，但主模型不收图 | 号池里另一个能看图的模型转述，不行再退本地视觉模型 | 一段文字描述 |
| `cam`（摄像头） | **只交局域网里的本地视觉模型** | 一段文字描述，照片本身永远不进主模型 |

**为什么屏幕给原图**：屏幕上全是字和界面，转述一遍就丢细节。本地小模型认字也不如大模型准，所以优先让主模型自己看。

**为什么主模型不收图要转述**：我给她换过一次纯文本模型，pi 对不收图的模型会把工具返回的图片整张丢掉，她调了 `look` 却什么都没拿到，等于瞎了。所以先判断主模型收不收图（`ctx.model.input` 里有没有 `image`），不收就把原图交别的模型写成文字。

**为什么摄像头只走本地**：屏幕截图我能控制涂黑；摄像头拍的是屋里的我，没法涂。这是隐私线，不是额度问题——所以硬写死，**她自己也改不了**：摄像头照片永远只走本地视觉模型，本地模型没配好就「这次看不到」，不会退到别的地方去。

另一条底线：同一路 60 秒内不重复取。这也防她一个劲地看。同一轮里并行调两次，只取一次，另一次如实告诉她「正在看」。

### 几个做进去的小事

- **每次调用现读 `agent/.env`**。早期进程环境优先，而宿主启动时把整份 `.env` 灌进了环境，之后我改了地址、换了 token，她一直用开机那份旧值，「改了不用重启」并不成立。现在以 `.env` 为准，环境变量只补 `.env` 里没写的键。
- **坏图不交出去**。认文件头，JPEG 还要有结尾标记 `FFD9`；头好尾断的图交给主模型，整轮都会 400。认不出、超过 8 MB，都当「这次没看到」。
- **没看成不占窗口**。取图失败、传到一半断了，60 秒的窗口还给她，让她能再试。
- **说实话**。没配好、连不上、模型没回，工具返回里都明说「这次没看到，照实说，别猜」，描述里没写的东西她不能补。

## 从壳里取图，到只剩 `look`

| 时间 | 变化 |
|---|---|
| 2026-09-17 | 采集端 + 壳里一个「眼睛」模块：定时取一帧，交视觉模型，存下观察。同一天加了 `/cam` 和「在场检查」，摄像头里没人就不主动开口 |
| 2026-10-14 | 脑里有了 `look` 工具，她可以自己决定看不看。壳里同时还留着一条路：她在回复里写 `[[LOOK:his]]` 标记，壳去取图，再用一条括号旁白把结果塞回给她 |
| 2026-10-15 | 加 `--lan`；`.env` 改成现读 |
| 2026-10-16 | 撤掉壳里直接取图（`albion-eyes.ts`、`[[LOOK:his]]` 标记、`eyes-*` 设置），只剩 `look` 一条路 |

撤的原因，和 08 讲的是同一件事：主动对话的决定权整个交给了她，壳只剩门铃和播放器。壳里那三样——定时器、摄像头当闸门的在场检查、`[[LOOK:his]]` 标记——就都没有存在的理由了。

现在壳里不碰任何图。要看东西，就是她调 `look`。

## 你可以怎么做

最小版：一个 Python 文件，只用标准库和系统自带的截图能力（Windows 的 PowerShell），57 行，有 token，没有涂黑。

先建 `token.txt`，只写一行 token（随便生成一串，别提交进 Git）。让 Python 自己写文件，别用 `>` 重定向——Windows PowerShell 5 的重定向会写成 UTF-16：

```
python -c "import secrets, pathlib; pathlib.Path('token.txt').write_text(secrets.token_urlsafe(18))"
```

`mini_eyes.py`：

```python
import subprocess, sys, tempfile, secrets, threading
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path

lines = Path("token.txt").read_text(encoding="utf-8-sig").splitlines() if Path("token.txt").exists() else []
TOKEN = next((s.strip() for s in lines if s.strip()), "")
if not TOKEN:
    sys.exit("token.txt 缺失或为空，不起")  # 宁可不起，也别用默认值

PS = r'''
Add-Type -AssemblyName System.Windows.Forms,System.Drawing
Add-Type -MemberDefinition '[DllImport("user32.dll")] public static extern bool SetProcessDPIAware();' -Name D -Namespace A
[A.D]::SetProcessDPIAware() | Out-Null
$v = [System.Windows.Forms.SystemInformation]::VirtualScreen
$b = New-Object System.Drawing.Bitmap $v.Width, $v.Height
[System.Drawing.Graphics]::FromImage($b).CopyFromScreen($v.Left, $v.Top, 0, 0, $b.Size)
$b.Save($args[0], [System.Drawing.Imaging.ImageFormat]::Jpeg)
'''
ps1 = Path(tempfile.gettempdir()) / "mini_eyes.ps1"
ps1.write_text(PS, encoding="utf-8-sig")
lock = threading.Lock()  # 截屏不能并发

def shot() -> bytes:
    out = Path(tempfile.gettempdir()) / "mini_eyes.jpg"
    with lock:
        subprocess.run(["powershell", "-NoProfile", "-ExecutionPolicy", "Bypass", "-File", str(ps1), str(out)],
                       check=True, timeout=60, creationflags=0x08000000)
        data = out.read_bytes()
        out.unlink()
    return data

class H(BaseHTTPRequestHandler):
    def reply(self, code, body, ctype="application/json"):
        self.send_response(code)
        self.send_header("Content-Type", ctype)
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def do_GET(self):
        if self.path == "/health":
            return self.reply(200, b'{"ok": true}')
        if self.path == "/shot":
            got = self.headers.get("Authorization", "").removeprefix("Bearer ")
            if not secrets.compare_digest(got.encode(), TOKEN.encode()):
                return self.reply(401, b'{"error": "unauthorized"}')
            try:
                return self.reply(200, shot(), "image/jpeg")
            except Exception:
                return self.reply(500, b'{"error": "capture failed"}')
        self.reply(404, b"{}")

    def log_message(self, *a):  # 默认日志带请求行，不要
        pass

bind = sys.argv[1] if len(sys.argv) > 1 else "127.0.0.1"
ThreadingHTTPServer((bind, 8790), H).serve_forever()
```

跑起来、验证（先在本机，确认能出图）：

PowerShell 里 `curl` 是 `Invoke-WebRequest` 的别名，要写 `curl.exe`：

```
python mini_eyes.py
curl.exe http://127.0.0.1:8790/health                                # {"ok": true}
curl.exe -o NUL -w "%{http_code}\n" http://127.0.0.1:8790/shot       # 401，没带 token
curl.exe -H "Authorization: Bearer <你的 token>" -o shot.jpg http://127.0.0.1:8790/shot
```

我实测的结果：缺 `token.txt` 时退出码 1；没带 token 是 401；带了 token 返回 200，一张 1200×1920 的屏约 430 KB，0.5 秒。打开 `shot.jpg` 看是不是你的屏幕。

要让另一台机器取，把绑定地址换成这台的 Tailscale 地址：

```
python mini_eyes.py <主力机 Tailscale IP>
curl.exe -H "Authorization: Bearer <你的 token>" -o shot.jpg http://<主力机 Tailscale IP>:8790/shot
```

接着把它从「一个工具」变成「她的眼睛」，需要补的就是上面几节：

1. **涂黑**。最小版没有，别直接把它接到会把图发给云端模型的地方。照 `capture_agent.py` 里 `$REDACT_WORDS` 和 `IsPasswordProperty` 那两段加，失败就返回 500。
2. **摄像头**。`ffmpeg -f dshow -i video=<设备名> -frames:v 1 -y out.jpg`，设备名用 `ffmpeg -list_devices true -f dshow -i dummy` 查；画面歪了再加 `-vf transpose=1`。
3. **谁来看**。屏幕图交能看图的模型；摄像头图只交你自己机器上跑的模型。这一条是在你的 agent 这边做，不是采集端的事。

我测这个示例时自己撞到一个坑：Python 的 HTTP 服务在 Windows 上默认允许同一个端口再绑一次，不报错，请求会落在先绑的那个进程上。你换端口试之前，先 `netstat -ano | findstr :8790` 看一眼有没有别人占着，不然 curl 回来的是别的服务的答案。

## 经验

- 敏感的东西在最靠近源头的地方处理，别指望下游「自觉不看」。
- 缺 token 就不起、涂黑失败就不出图：这类东西宁可明明白白坏掉，别悄悄退化成不安全的样子。
- 取到的图交给谁，是一个**隐私问题**，不只是模型能力问题。把规则写成她改不了的底线，别写成提示词。
- 跨机器取图，先量一下实际耗时。慢十几倍多半是走了中继，不是代码的问题。
