# 00 复现向导（给 agent 读）

读者是替人搭一套同类 AI 桌宠的 coding agent。人看的踩坑笔记在 [README](README.md)，本篇是执行清单：按阶段顺序做，每阶段「前置 → 操作 → 验收」，原理和坑读对应教程。

阶段 1–10 对应教程 01–10。本向导按作者的机器写成，路径、端口、角色名都是作者的；作者的环境之外没有第三方整机走通过的记录，卡住就停下报告。

## 给 agent 的执行约定

1. 按阶段顺序做，不跳阶段。标「可选」的阶段，人明确说不要才跳。
2. 每阶段开始前核对「前置」是否满足；做完立刻跑「验收」。验收不过，停下，把命令、输出、日志末尾 30 行报给人。不猜，不绕过，不降级验收标准。
3. 下表的东西只能由人提供。用到时停下问人，不要自己编、不要去网上找替代品。
4. 密钥、token、人设、聊天数据只写进不入库的文件（`.env.local`、`agent/.env`、`agent/models.json`、`pet/tools/eyes/token.txt`、`ov.conf`）。不在命令行、日志、提交、回复里出现密钥明文。
5. 不 force push，不改写历史，不 `git add -f` 私密或备份目录；提交前跑 `python tools/check_repository.py`。
6. 命令只用本向导和 `docs/REBUILD.md` 里已有的。仓库没有自动化的步骤，按「操作」里写的产物路径手工完成，完成后验收。
7. 路径是作者的：仓库根 `D:\AI\Wife`，WSL 脑 `/root/albion-pi`，记忆服务 `D:\AI\openviking`。要换路径，先搜这些路径的斜杠和反斜杠写法，逐处改并验证（见 `docs/REBUILD.md`「克隆与选择版本」）。第一次复现建议原样用这几个路径。
8. 在 Windows 上拉起常驻服务，用仓库的 `_silent_run.ps1`（和 `start_all.bat` 同一套），别用 `start /min` 或自写包装 bat，免得桌面弹一堆控制台、也免得服务随会话结束。

## 阶段 0 环境准备

**目标**：工具链齐全，仓库克隆到位，布局门禁通过。

**前置**：Windows 11，管理员权限可用，能访问 GitHub、npm、PyPI、Hugging Face、ModelScope。

**需要人提供**：Tailscale 账号（可选，仅阶段 9 跨机用）；GitHub 登录（`gh auth login` 由人完成，不要把 token 写进命令或 URL）。

**操作**：

| 项 | 版本 | 说明 |
|---|---|---|
| WSL2 + Ubuntu | 发行版名 `Ubuntu` | 脑的启停脚本里写死 `wsl -d Ubuntu`。`%USERPROFILE%\.wslconfig` 里 `[wsl2]` 下写 `networkingMode=mirrored`，改完 `wsl --shutdown` 重进。Windows 要能用 `127.0.0.1:8650` 访问 WSL 里的脑，靠的就是 mirrored |
| Git、GitHub CLI | 当前版 | `gh auth status` 能通过 |
| Python（Windows 系统） | 3.13 | 挂件启动器写死 `%LOCALAPPDATA%\Programs\Python\Python313\pythonw.exe`；`tools/`、`tests/` 的标准库脚本用它跑 |
| uv | 当前版 | 阶段 4 建 TTS 环境用 |
| Node + pnpm（Windows） | 以 `docs/REBUILD.md`「桌面壳」为准：作者机器 Node `22.23.2`、pnpm `10.32.1`；`shell/package.json` 声明 `pnpm@11.24.0` | 版本不一致已登记，不要盲改 lockfile |
| NVIDIA 驱动 + CUDA | 能跑 CUDA 12.8 的 wheel（作者驱动 610.88） | `nvidia-smi` 能列出显卡 |
| ffmpeg | 在 PATH 里 | 仅阶段 9 摄像头用 |
| Tailscale | 当前版 | 可选，仅阶段 9 |

Python 解释器共三套，别混：Windows 系统 3.13（挂件、通用脚本）、`tts/irodori/.venv` 3.10.20（TTS，阶段 4 建）、`tts/GPT-sovits/runtime/python.exe` 3.9.13（耳朵和眼睛启动器，阶段 6 建）。版本清单在 `config/rebuild/*.json`。

## 阶段 1 找角色模型（教程 [01](01-找到角色模型.md)）

**目标**：本机有一份能用的 Live2D（Cubism 4，`.moc3` + `model3.json`）或 Spine 3.8 模型，且已核对里面有你想要的部件和交互数据。

**前置**：阶段 0。

**需要人提供**：模型文件本身；解包得来的话，解包工具和合法来源由人负责。

**操作**：

1. 让人给出模型；按教程 01 的「拿到之后先检查这几项」逐项核对：格式版本、模型里有什么、有没有作者的交互数据（`model0.json` / `modelN.json`）、画布形状。
2. 放置（作者的约定路径，文件名来自 `config/rebuild/assets.json` 的 `local_assets`）：

|---|---|
| `shell/packages/stage-ui/src/assets/live2d/models/albion.zip` | Live2D 包 |
| `shell/packages/stage-ui/src/assets/spine/models/albion-spine-38.zip` | Spine 3.8 包 |

   这两个路径被壳源码按名字引用（`shell/packages/stage-ui/src/stores/display-models.ts`、`shell/packages/stage-ui/src/albion/albion-pet.ts`）。第一次复现沿用这两个文件名。换角色要搜这两处引用。

**验收**：

## 阶段 3 脑与人设（教程 [03](03-口癖和人设.md)）

**目标**：WSL 里的 Pi 脑在 :8650 回话，带她自己的口吻和 `<|ACT:…|>` 表情标记。

**前置**：阶段 0、2（`API_SERVER_KEY` 已生成）。

**需要人提供**：

| 东西 | 去处 |
|---|---|
| 人设 `SOUL.md` | WSL `/root/albion-pi/agent/SOUL.md`（启动时生成 `agent/SYSTEM.md`；SOUL 只在生产里改，不入库） |
| 大模型访问 | `/root/albion-pi/agent/models.json` 里你的 provider 与 key；`/root/albion-pi/agent/.env` |

**操作**（`docs/REBUILD.md`「WSL 脑与私人配置」、`integrations/pi-brain/README.md`）：

1. WSL 里装好 Pi（`@earendil-works/pi-coding-agent`，脑的扩展按 `/usr/local/lib/node_modules/@earendil-works/pi-coding-agent` 加载）和 Node。**仓库没有自动化的安装脚本，也没写具体版本**，见末尾「没把握」。
2. 把仓库 `integrations/pi-brain/` 的内容放成 WSL 的 `/root/albion-pi/`，换行保持 LF。
3. 在 `/root/albion-pi/agent/` 下手工建不入库的文件：

| 文件 | 内容 |
|---|---|
| `.env` | `API_SERVER_KEY`（与阶段 2 一致）；阶段 7、9 再追加 `OPENVIKING_*`、`ALBION_EYES_*`；provider 需要的 key（如 `COMMANDCODE_API_KEY`） |
| `SOUL.md` | 人设，要求她每条回复开头带 `<|ACT:{"emotion":"…"}|>` 标记（验收脚本和壳的表情都认它） |
| `models.json` | 你的 provider（仓库里的是作者的示例，只含本地占位 key，**不要原样覆盖生产文件**）。provider 级 `api` 用 `openai-completions` |

4. 选模型：优先级 `ALBION_PROVIDER`/`ALBION_MODEL` 环境变量 > magpie 写的默认设置 > 兜底（见 `docs/REBUILD.md`）。没有 magpie 时，用环境变量指定一次，如 `ALBION_PROVIDER=<provider> ALBION_MODEL=<model> bash start.sh`。

```powershell

```

## 没把握和仓库缺的自动化

这些地方别人复现会卡，做到时停下问人或报告：

1. **WSL 里装 Pi 和 Node 没有脚本、没写版本。** 只知道包名 `@earendil-works/pi-coding-agent`，全局安装路径 `/usr/local/lib/node_modules/@earendil-works/pi-coding-agent`，Node 在作者机器上被搬到 `runtime/node/` 再软链到 `/usr/local/bin`。
2. **把 `integrations/pi-brain/` 部署到 `/root/albion-pi/` 没有脚本**，只有只读的 `tools/check_pi_brain_sync.py` 核对；`agent/.env` 没有 `.env.example`，必需变量要从 `docs/REBUILD.md` 和各教程拼。
3. **`SOUL.md` 不入库**，如何写出让她带 `<|ACT:…|>` 标记的人设没有模板；`accept.sh` 的 ACT 检查依赖它。
4. **无 Magpie 时脑用哪个模型**：`follow_settings.py` 读 Magpie 写的 `/root/.pi/agent/settings.json`，兜底是 `commandcode/deepseek/deepseek-v4-flash`；用自己的 provider 要靠 `ALBION_PROVIDER`/`ALBION_MODEL` 环境变量，且 `_启动脑Pi.ps1`、看门狗启动时不带它们，重启后是否保持没有验证。仓库里没有 Magpie、Command Code 代理、grok 号池的安装说明（号池 :8000 只在 `docs/REBUILD.md` 有开机拉起的描述，两个脚本不入库）。
5. **翻译桥的非作者线路**：`TTS_TRANSLATE_BACKEND=api` 路线 `docs/REBUILD.md` 自己说没在作者机器上配置过；桥的首腿只认 Magpie 和 Command Code。
6. **耳朵的 `tts/GPT-sovits/runtime/python.exe`（3.9.13）怎么建没有脚本**，只有 `config/rebuild/stt-environment.json` 的 252 项清单，且 `docs/REBUILD.md` 说它不保证跨平台按全表装成功。眼睛的启动器也借用这个 python。
7. **TTS 环境命令**（`uv sync --frozen --extra cu128`）`docs/REBUILD.md` 自己标注未在新机器执行过；50 系以外的显卡没验证。
8. **角色声音数据准备没有脚本**：扒音频、对齐官方原文、整理成 HuggingFace dataset 全靠手工（教程 04 只讲方法）。`tools/relabel_albion.py` 是作者的重标注脚本，写死了阿尔比恩的数据。
9. **换角色要改多处硬编码**：模型 zip 文件名、`ships.json` 与桥里的音色名 `albion`、验收脚本里的 `"id": "albion"`。第一次复现建议沿用 `albion` 这个内部名。
10. **壳的首次配置**：provider、key、布局、角色卡在 Electron 用户数据里（`docs/REBUILD.md`），`.env.local` 只覆盖其中一部分，教程 02 又说默认值要改 fork 里 store 的默认值；陌生机器首次启动后壳里还需要手工设置哪些项，仓库没有清单。
11. **硬编码路径**：`AlbionStatus.vbs` 写死 `Python313`；`capture_agent.py` 的 ffmpeg 默认路径 `D:/ffmpeg-…`（不存在时退回 PATH 里的 `ffmpeg`）和摄像头名 `FHD Camera`；挂件快照默认路径里写死发行版名 `Ubuntu`。
12. **视觉机没有部署脚本**：Docker、llama.cpp、Qwen3-VL 4B 的启动命令和模型文件来源仓库里没有，只有防火墙规则的文字描述；作者的视觉机是 i5-9400F、GTX 1660 Ti 6 GB、16 GB 内存，操作系统未记录（防火墙规则文字写的是 Linux 路径 `/usr/local/bin/docker-user-rules.sh`，另有记录说它是 Windows 机器，两者对不上）。
13. **挂件依赖** `numpy`、`Pillow` 没有清单。
14. **OpenViking 的 `ov.conf` 没有模板**，字段只在教程 07 的表里；守护脚本默认 `D:\AI\openviking`。
15. **`tests/pet/*.mjs` 探针退出码不可靠**（`tests/README.md`），验收看输出结论，不看退出码。
16. **没有任何一键安装脚本。** 本向导里的「一键」只指阶段完成后的 `一键启动-构建版.bat`。
