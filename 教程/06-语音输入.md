# 06 语音输入：让她听得见、听得准、不抢话

目标：我对着麦克风说话，她能听到、转成文字，等我说完再回答；不会把噪声当成我在说话，也不会把她自己的声音录进去。

AIRI 壳本来就有语音输入：VAD（判断有没有人在说话）+ 语音识别（ASR）。我用的时候基本每一环都出过问题。

## 1. VAD 根本没加载

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 开了麦克风没反应 | VAD 模型运行时从 HuggingFace 在线拉，国内网络拉不下来 | 把模型文件放到本地，从本地加载 |
| 开发版好了，打包版又不行 | 打包后页面是 `file://`，绝对路径找不到文件 | 用相对路径 |
| 还是不行 | VAD 依赖的 ONNX Runtime 脚本（`.mjs`）也是从 CDN 拉的 | 一起本地化 |

> 打包版和开发版的加载路径不一样，这类问题只在打包版出现，两边都要测。

## 2. 什么时候算「我说完了」

- **断句交给 VAD 一个人管**。壳里原本还有一套按音量判断的兜底，两套同时在判断，经常一套说「还在说」、另一套说「说完了」。我让 VAD 独占断句。
- **别丢已经转好的文字**。我说话中间停顿一下，前半句已经转写完了，后半句开始时前半句被清掉了。改成累积，整段说完再发。
- **停顿 2 秒再发**：说完后等 2 秒，期间 VAD 又检测到说话就继续等（hold）。缓冲区是空的时候也要记 hold，不然刚好在空档里开口会被切开。再加一个总超时兜底，免得一直等下去。

## 3. 噪声和空录音

- **噪声别弹警告**。键盘声、咳嗽被 VAD 当成说话，识别出来是空的，壳就弹「识别失败」。空结果静默丢掉就好。
- **先看 `active-model` 和 `active-provider` 有没有被清空**。现在默认值已经写死成 `paraformer-zh` 和内置的 OpenAI 兼容转写 provider（见 `shell/packages/stage-ui/src/stores/modules/hearing.ts` 和 `albion-defaults.ts`），首次启动不会是空的。但如果手动改坏了或被旧角色卡盖成空，壳不报错、只是什么都不发，听不见的时候还是先查这两项。

## 4. 别把她自己的声音录进去

她说话时麦克风会录到扬声器的声音，识别成文字再发给她，她就开始跟自己聊天。

- 打开回声消除。
- 她说话时暂停听写，说完再恢复。停止和恢复的**顺序**要对：先停听写，再开始播放；播放完再恢复听写。
- 想彻底避免，就用按键说话（push-to-talk），我给它配了一个全局快捷键。

## 5. 识别模型怎么选

中文识别我对比过几个本地模型，看两样：延迟和显存。显存要和 TTS 一起算，两个都常驻在同一块 8 GB 显卡上，ASR 占多了 TTS 就开始变慢（见第 04 篇）。

| 模型 | 跑在哪 | 速度 | 显存 | 准不准 |
|---|---|---|---|---|
| faster-whisper `small` | GPU | 没记 | 没记 | 把「我是阿尔比恩」听成「或是阿尔比恩」 |
| faster-whisper `large-v3`（默认参数） | GPU float16 | 6 秒中文要 6.0 秒 | 约 3 GB | 一字不差 |
| faster-whisper `large-v3`（调过参数） | GPU float16 | 6 秒中文 0.81 秒 | 约 3 GB | 一字不差 |
| **paraformer-zh**（+ fsmn-vad + ct-punc） | **CPU** | 9 秒中文 0.59–0.69 秒 | **0** | 中文准，自带标点 |

（准确度是拿 Windows 自带的中文语音合成念同一句话测的；whisper 调参是 `beam_size=1`、`without_timestamps`、`condition_on_previous_text=False`。）

最后选了 paraformer：中文专用，跑 CPU 也比 GPU 上的 large-v3 快，显存一点不占。换过去以后整机显存从 7.3 GB 降到 3.4 GB，省出来的全给 TTS。whisper-large-v3 我留着当多语种备选，切换只改 `ALBION_STT_ENGINE`，接口和模型名不变，壳那边不用动。

起耳朵之前的几个细节：

- **先建环境**：`ear/start_ear.bat` 找不到 `ear/.venv` 会直接退出。在仓库根目录跑 `uv sync --directory ear`，或者跑 `powershell -NoProfile -ExecutionPolicy Bypass -File tools/setup/setup_stt_runtime.ps1`（支持 `-DryRun`，完整安装步骤见 [00 复现向导](00-复现向导.md) 阶段 6）。
- **启动后台预热**：默认启动时后台线程先预热一次模型，不然第一句话要等 6–8 秒。
- **下载来源**：从 HuggingFace 下 whisper 模型要设 `HF_HUB_DISABLE_XET=1`，否则会被导到国外的 CDN 上超时。paraformer 从 ModelScope 下，国内没这个问题。
- **启动与路径**：起耳朵用 `ear/start_ear.bat`（:9882），改端口或模型目录前先看 `docs/ASR路径清单.md`。

耳朵的可调项统一写在 `config/local.env`（模板见 `config/local.env.example`）：

| 变量名 | 默认值 | 说明 | 改完重启 |
|---|---|---|---|
| `ALBION_STT_ENGINE` | `paraformer` | 引擎选择：`paraformer`（中文 CPU）或 `whisper`（多语种） | 耳朵 :9882 |
| `ALBION_STT_PORT` | `9882` | 监听端口 | 耳朵 :9882 |
| `ALBION_STT_DEVICE` | `auto` | `auto` / `cuda` / `cpu`；paraformer 在 `auto` 下走 CPU | 耳朵 :9882 |
| `ALBION_FUNASR_ROOT` | `ear/models/modelscope/iic` | paraformer 三件套根目录；换目录后里面三个模型子目录名仍必须一致 | 耳朵 :9882 |
| `ALBION_STT_MODEL` | `small` | 仅 `whisper` 引擎用，填模型名或本地路径 | 耳朵 :9882 |
| `ALBION_STT_PRELOAD` | `1` | 启动时后台预热模型（paraformer 和 whisper 都会生效）；设 `0` 关闭 | 耳朵 :9882 |

## 6. 字幕

屏幕上的字幕其实走两条完全不同的链，排查问题时别混在一起：

### 识别字幕（我说的话）

壳本地维护，只管麦克风识别出来的文字。临时识别结果很快消失，最终确认的文字停久一点，按类型分别设停留时间（TTL）。这一路坏了，看耳朵（:9882）和壳的听写状态。

### 她的话字幕

不是壳本地拼的，走的是流式语音网关（:9885）和翻译桥（:9881）。平时显示她说的中文；她直出日语时先上日语原文，等 `/v1/caption` 翻出中文后再发 `display.caption` 替换。完整流程、晚到补屏和几个开关见 [05 流式语音](05-流式语音.md#字幕直出日语时的中文字幕)。

## 测试的坑

- **假麦克风测不了**。Electron 的假音频设备（`--use-fake-device-for-media-stream`）给的是静音或者固定的哔声，VAD 不会触发。要用真实的音频流测，或者干脆自己对着麦克风说。
