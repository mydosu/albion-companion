# 11 状态挂件：一眼看到她最近在干嘛

目标：在 Windows 桌面上放一个半透明毛玻璃小挂件，一眼能看到她最近在干嘛：调了什么工具、看或改了哪个文件、当前的心情，以及今天一共聊了多少句。

## 遇到什么问题

桌面角色平时在后台跑着，或者缩在屏幕一角。我想知道她是不是醒着、刚才读了哪本书、翻了什么笔记，以往要翻控制台里滚动的日志。

我想要的是一个常驻桌面、不挡视线的仪表盘：平时静静挂在角落，瞥一眼就能看到她刚才的动静；想看细一点时点一下展开，不看时收起。

## 为什么会这样

挂件早期直接读脑的 `state.db`，后来改成脑写 `state/widget.json`、挂件只读这份快照。这样设计主要出于三点考虑：

1. **不跨 WSL 开 SQLite**：挂件在 Windows，数据库在 WSL 里，跨系统去开 SQLite 连接有网络和锁的开销。
2. **避免读到半截文件**：脑端先把 JSON 写到临时文件，再用原子替换覆盖目标文件，挂件不会读到写了一半的坏数据。
3. **脑出问题时挂件照常画**：挂件只读这份文件。脑端停了或者 WSL 关了，挂件只显示多久前成功过，界面不会卡住或崩溃。

## 我怎么解决的

### 整体架构：脑端写快照，桌面只读

挂件和脑之间通过一份快照解耦：脑负责写小文件，挂件只读。

```
脑宿主 :8650（WSL，bin/server.py 后台线程）
   │ 每 5 秒查一次只读 SQLite 库（PRAGMA query_only=ON）
   ▼
state/widget.json（原子写入）
   │ \\wsl.localhost\Ubuntu\root\albion-pi\state\widget.json
   ▼
Windows 桌面挂件（pet/widget/albion_status_widget.pyw）
   └─ 5 秒轮询只读这份快照，渲染毛玻璃卡片（:47654 单实例）
```

### 脑端谁在写快照、记什么

快照由脑宿主的后台守护线程负责写入（`integrations/pi-brain/bin/server.py` 启动时拉起 `widget_snapshot.loop`），核心逻辑在 `integrations/pi-brain/bin/widget_snapshot.py`：

- 每 5 秒查一次活动数据库 `state/state.db`（`INTERVAL = 5`，使用 `file:...mode=ro` 只读连接并设 `PRAGMA query_only=ON`，2 秒超时，不影响正常聊天）；
- **只取真实桌面会话**（`SESSION = "albion-desktop"`），隔离测试和探针数据；
- 采集并输出以下字段到快照：
  - `generated_at`：快照生成时间戳（秒）；
  - `last_tool`：最近调用的工具名（`tool_name`）、摘要与时间戳；
  - `last_action`：从 assistant 的工具调用里解析出的最近动作；
  - `work`：最近动过的文件，包含相对路径 `relative_path` 和时间戳 `mtime`；
  - `emotion`：从回复里的 `<|ACT:{"emotion":"..."}|>` 动作标签解析出的心情状态；
  - `idle_seconds` / `last_activity_at`：空闲秒数与最后活动时间；
  - `counts`：当前会话累计消息条数与工具调用次数；
  - `today_counts`：今天从零点起累计的消息条数与工具调用次数。
- **原子写文件**：先把 JSON 写到 `state/widget.json.tmp`，再用 `os.replace` 瞬间替换到 `state/widget.json`，避免挂件读到写入一半的坏数据。

### 桌面挂件：Windows 分层窗口与毛玻璃

挂件是纯 Windows 原生 Python 脚本 `pet/widget/albion_status_widget.pyw`：

- **只读快照**：默认读取 `\\wsl.localhost\Ubuntu\root\albion-pi\state\widget.json`（可通过环境变量 `ALBION_WIDGET_SNAPSHOT` 覆盖），每 5 秒轮询一次；
- **失效兜底**：快照带 `generated_at`。如果文件不存在、损坏，或超过 60 秒没有更新（`STALE_S = 60`），挂件显示「暂时读不到最近记录 · 上次成功 X 分前」；
- **毛玻璃效果**：通过 Windows API 创建无边框分层窗口（`WS_EX_LAYERED | WS_EX_TOOLWINDOW | WS_EX_TOPMOST`），截取挂件所在屏幕区域做缩小（`FROST_SCALE = 6`）与高斯模糊，再与淡蓝白色（`GLASS_BASE = (218, 230, 242)`）半透明混合，每 50 毫秒刷新一帧；
- **避开遮挡**：检测窗口是否被系统顶层弹层（如 ControlCenterWindow）或其它不透明窗口挡住。被挡住时暂停背景重算，避免 CPU 白费和挂件闪烁；单独放过 AIRI 的透明模型层，模型贴在挂件旁边不算遮挡。

### 窗口置顶、拖动记位置与展开详情

- **置顶与位置记忆**：窗口始终置顶（`WS_EX_TOPMOST`）。左键按住拖动超过 3 像素即为移动窗口，松开时将坐标原子写入 `albion_status_widget_pos.json`，下次启动自动恢复在相同位置；
- **折叠与展开**：
  - 默认卡片（高 160 像素）：显示标题、多久前活动、最近工具、最近动作（文件路径+时间）、心情与今日累计；
  - 展开卡片（高 236 像素）：鼠标左键短按卡片切换展开状态，补充显示最近工具的具体时间、最近动作时间，以及会话历史总累计；
- **文字跑马灯**：当文件相对路径或工具名过长超出卡片宽度时，左侧标签保持固定，右侧文字平滑循环滚动，不再生硬切成省略号；
- **文件只显路径**：文件类动作只显示路径和修改时间，不展示正文；同时用 `clean()` 过滤掉 Bearer 和 token。

### 字体与单实例端口锁

- **字体**：优先加载本地自带的开源站酷快乐体（`pet/widget/fonts/ZCOOLKuaiLe-Regular.ttf`）；如果缺失则换用系统自带的 MiSans、微软雅黑或 Arial；
- **单实例锁（端口 47654）**：启动时尝试绑定本地 TCP 端口 `127.0.0.1:47654`（`guard.bind(("127.0.0.1", 47654))`）。如果端口已被占用，说明已经有挂件在跑，当前进程直接静默退出（`sys.exit(0)`）。不用复杂的跨进程锁，一个 socket 搞定防重；
- **右键菜单**：右键点击卡片弹出系统菜单，提供“退出”选项。

### 启动方式：静默无黑框拉起

整套系统的根启动器 `start_all.bat`（第 106 行）通过 `wscript` 调用同目录的 `pet/widget/AlbionStatus.vbs`：

```vbs
Set shell = CreateObject("WScript.Shell")
here = CreateObject("Scripting.FileSystemObject").GetParentFolderName(WScript.ScriptFullName)
py = shell.ExpandEnvironmentStrings("%LOCALAPPDATA%\Programs\Python\Python313\pythonw.exe")
shell.Run """" & py & """ """ & here & "\albion_status_widget.pyw""", 0, False
```

用 `pythonw.exe` 配合窗口样式 `0` 启动，既不弹黑框控制台，也不阻塞批处理继续执行后面流程。

## 踩过的坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 挂件显示总比她慢半拍 | `albion-turn.ts` 原来只在整轮说完（`agent_end`）才写 `state.db`，一轮常在 40 秒以上；快照每 10 秒导一次、挂件每 10 秒读一次（5 分钟无活动放慢到 30 秒） | 工具结果一出来就立刻写 tool 行；快照改 5 秒导出，挂件统一 5 秒轮询，最坏延迟压到 10 秒左右 |
| 读书翻笔记时卡在旧文件 | 原来只认 `write_file` / `patch` 写操作，`read_file` 没记路径，只读活动不刷新 | 把 `read_file` 的 `resolved_path` 纳入文件归因，与文件修改时间比较取最新的一条 |
| 被别的窗口挡住时闪烁变色 | 以前整类放过 Chromium 窗口，同席、Hermes 桌面端盖住挂件时还在截它们反算背景 | 遮挡检测判断有其它顶层窗口挡住就暂停重算背景；只放过 AIRI 透明模型层 |

## 你可以怎么做

给自己的桌面助理做一个状态挂件，最小只需这几步：

1. **脑端起一个后台定时线程**：
   每 5 秒查一次本地会话记录，拿最近一条消息、工具名和文件变动，拼成字典写入 `state/widget.json`（写入 `.tmp` 后改名替换），附带 `generated_at` 时间戳；
2. **写一个无边框分层窗口**：
   在 Windows 上用 Python + Pillow + ctypes 启动一个 `WS_EX_LAYERED | WS_EX_TOOLWINDOW | WS_EX_TOPMOST` 窗口，每 5 秒读取一次快照更新文字；
3. **加单实例绑定与坐标记忆**：
   启动时 `bind(("127.0.0.1", 47654))` 防重；鼠标拖拽释放后把 `x, y` 坐标写进 JSON，下次启动先读坐标；
4. **静默拉起**：
   写一个 4 行的 VBS 脚本，用 `pythonw.exe` 拉起 `.pyw`，塞进你的一键启动批处理里。

## 经验

- 挂件和脑之间用快照解耦：脑负责写小文件，挂件只读，两边互不阻塞。
- 桌面看板只看状态（动了哪个文件、多久前），不放长正文。
- 桌面驻留程序顺手加上防重开（端口锁）和无黑框启动（pythonw）。
